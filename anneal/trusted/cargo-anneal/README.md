# Anneal

![Anneal logo][logo]

*Logo by [tinyneonspark](https://www.instagram.com/tinyneonspark/).*

Anneal is an experimental Rust verifier that uses Lean 4 to check proofs
about Rust programs. The current alpha checks one selected Rust function on
x86-64 Linux with glibc. See the [alpha guide] for setup and an example proof.

[logo]: https://raw.githubusercontent.com/google/zerocopy/main/anneal/docs/images/logo.svg
[alpha guide]: https://github.com/google/zerocopy/blob/main/anneal/docs/alpha.md
