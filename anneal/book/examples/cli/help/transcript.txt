$ cargo anneal --help
Formally verify Rust programs in Lean 4

Usage: cargo anneal [COMMAND]

Commands:
  setup   Install or reuse the versioned Anneal toolchain archive
  init    Scaffold starter Spec.lean and Proof.lean proof files
  skill   Print the bundled agent skill
  verify  Capture a configured compilation and check its authored source proof
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Also accepts direct invocation as cargo-anneal <COMMAND>.
