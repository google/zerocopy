#### 1.3 `CHASE-SQL` Algorithm 3: Ordered vs. Unordered Loops, Copeland Clone Bias, and Deduplicated Bradley–Terry

`CHASE-SQL` (`2410.01943v1` §3.5 `L314–341`, Table 2 `73.01%` dev / `73.0%` test, `82.79%` oracle upper bound `L461`) runs Algorithm 3 over all $K = 21$ candidates (`7` DC + `7` QP + `7` OS) using fine-tuned `Gemini-1.5-Flash` (`p = 0.7101` binary accuracy vs. `0.6021` untuned `Claude-3.5-Sonnet`, `0.6398` `Gemini-1.5-Pro`, `0.6428` `Tuned Gemma 2 9B`, **Table 5**, `L434–442`) **without pre-collapsing identical execution-result clusters**. Separating literal ordered pairs from unordered implementations (`Probe 1d`, $K = 21$, wrong cluster $|W| = m = 14$, $6$ wrong singletons, $1$ correct $c^*$, $n = 2{,}000$ seeded tournaments) resolves two distinct regimes:

1. **Literal Ordered-Pair Loop ($1 \le i \neq j \le K$, `L318 + L333`, `238` directed LLM calls):** Comparing both $(c_i, c_j)$ and $(c_j, c_i)$ awards `1` point each to $c_i$ and $c_j$ when $\mathrm{er}(c_i) = \mathrm{er}(c_j)$ (canceling `L335`'s claimed consistency bonus to `50%`). Every wrong candidate satisfies:
   $$\mathbb{E}[r_c] = (m - 1) + (K - m - 1) + 2(1 - p) = K - 2p = \mathbf{19.5798} \quad (\text{independent of } m!), \qquad \mathbb{E}[r_{c^*}] = 2(K - 1)p = \mathbf{28.4040}.$$
   Across `2,000` i.i.d.-noise tournaments, literal ordered Algorithm 3 achieves **`89.02%` fair-tie win rate (`86.90%` first-tie)**—outperforming naive *unweighted* `1`-vote (`45.29%`, `28` calls) and `3`-vote majority (`64.52%`, `84` calls) pre-deduplication because unweighted deduplication discards $2m = 28 \to 1..3$ independent noisy comparisons against $W$.
2. **Unordered-Pair Misimplementation ($1 \le i < j \le K$, `119` LLM calls):** Evaluating each unordered pair once with `w <- i` concentrates all $m - 1$ intra-cluster points onto lowest-indexed $c_0 \in W$, giving $\mathbb{E}[r_{c_0}] = \frac{K+m-1}{2} - p > \mathbb{E}[r_{c^*}] = (K - 1)p$ **if and only if** $m > 2Kp - K + 1$ ($m^* = \mathbf{9.82}$ at $p = 0.7101$, $m^* = \mathbf{5.29}$ at $p = 0.6021$). At $m = 14$, $16.2899 > 14.2020$, collapsing $c^*$ win rate to **`15.25%` (`10.25%` first-tie)** vs. **`69.68%`** under a symmetric `0.5/0.5` tie-split negative control.
3. **Copeland Clone Violation Under `i != j` vs. Budget-Matched Deduplicated Bradley–Terry (`196` calls):** Even under literal ordered pairs ($i \neq j$), uncollapsed Algorithm 3 **violates Tideman Clone Independence** when pairwise preferences are cyclic or order-sensitive: over 5 distinct clusters $\{C^*, A_1, A_2, D, B\}$ where $C^*$ uniquely wins the deduplicated tournament (`5` vs. `4` pts), duplicating inferior cluster $B$ (`3` pts) to `4` copies inflates distractor $D$'s score (`2–0` vs. each $B$ copy) from `4` to `10` pts vs. $C^*$'s `8` pts, **flipping the winner from $C^*$ to wrong query $D$**! ## Boundaries

- **`known not to apply` — Schema Pruning Below `~100–200` Columns and Static Dialect-Manual Stuffing:** `CHESS` `SS` lowers `BIRD` accuracy (`71.10%` without `SS` vs. `66.69%` low-budget with `SS`, `2405.16755v3`; `Maamari et al.` `2408.07702`), and static oracle dialect manuals reduce single-shot `DAIL-SQL + o1-preview` on `Spider 2.0-lite` (`12.60% → 9.51%`, `2411.07763v2` Table 10).
- **`known not to apply` — `CHASE-SQL` $m > 2Kp - K + 1$ Threshold Under Literal Ordered Pairs (`i != j`):** The intra-cluster `w <- i` subsidy threshold applies **only** if Algorithm 3 is misimplemented over unordered pairs ($i < j$); under literal ordered pairs ($i \neq j$), $\mathbb{E}[r_c] = K - 2p$ is independent of $m$ (`89.02%` win rate), though Tideman/Copeland Clone Independence still fails under cyclic preferences unless candidates are pre-deduplicated (`Probe 1d`).
- **`known not to apply` — Unconditional `Self-Debug > OpenHands` Dominance and Zero-Selection Pure `GroupKFold`:** `ScienceAgentBench` Table 3 uses `pass@3` oracle selection and flips to `OpenHands 27.5% > Self-Debug 23.5%` on `GPT-4o` With Knowledge (`2410.05080v3`); in `Probe 3b`, pure unpenalized `GroupKFold` selects `z_ent` in `5.0%` (`1/20`) of runs via training-fold Frisch–Waugh–Lovell entity demeaning rather than `0.0%`; and single-spec Lockbox confirmation without Lockbox specification-curve verification still leaks `4.5%` collider false positives at $\rho = 0.85$ (`Probe 4b`).
- **`not examined` — Visual Chart/Plot Grounding, Wet-Lab Hardware, and Literature-Only RAG:** Multimodal chart perception (`ChartQA`), GUI spreadsheet coordinate clicking (covered in `agent-structured-outputs-constrained-decoding-tool-schemas-and-computer-use`), wet-lab robotics, and non-computational literature synthesis were outside scope.
- **`unknown` — Live Cloud-Warehouse & 75-Competition GPU Leaderboard Uplift of `Q1`–`Q7`:** `Probe 1b`, `3b`, `4b`, and `5a` validate exact relational and statistical mechanisms on controlled local harnesses; end-to-end leaderboard deltas of `Q1`–`Q7` on proprietary `BigQuery`/`Snowflake` `Spider 2.0` and 75-competition `MLE-bench` clusters with newer frontier checkpoints remain unmeasured in public benchmarks.
