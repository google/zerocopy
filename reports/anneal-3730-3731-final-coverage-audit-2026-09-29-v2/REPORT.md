## Boundaries

- The **issue snapshot** was fetched at 09:06 UTC; the **package snapshot** is the eleven named packages present when `support/build_audit.py` ran afterward. A later issue edit or report completion requires a new audit or update; current GitHub status is not a claim about future state.
- A complete I049/C03/C04 is a direct Lean imported-definition case with the exact three launch commands. It does not attest loaded import hashes in every existing worker, prove supported refresh never works, or pick the Anneal worker policy. Similarly, complete I046/C13 is direct partial-file behavior only.
- A passing finite model or projection fixture establishes its own state space and invented syntax. It is not a proof that the real Anneal pipeline obeys those invariants. The checkout lacks that complete pipeline and Rust editor/MCP authority surface.
- The cached Linux overlayfs trial used real `.olean` bytes but no Linux Lean process. Two cached Lean versions were checked in separate builds; binary compatibility and a future upgrade are not established.
- The audit hashes/inventories report-owned support files. It does not rerun every old experiment, test every raw-event implication, independently reproduce every binary result, or make an adopted V2 architecture decision.
