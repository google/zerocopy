# Agentic Fuzzing Harness Synthesis, Greybox Power Schedules, Precondition Oracles, and Cybersecurity CTF Evaluation

## Summary

Primary-source synthesis across 18 fuzzing and offensive-security studies (2016–2025), line-level inspection of 15 pinned upstream repositories (`llvm/llvm-project`, `mboehme/aflfast`, `google/oss-fuzz-gen`, `ChatAFLndss/ChatAFL`, `fuzz4all/fuzz4all`, `andyzorigin/cybench`, `NYU-LLM-CTF/NYU_CTF_Bench`, `NYU-LLM-CTF/nyuctf_agents`, and 7 supporting repositories), and deterministic verification via `scripts/verify_fuzzing_ctf_agents.py` establish four core engineering findings:

1. **Single-Harness Exponential Scaling Wall vs. Bottom-Up Precondition Hazard (`Böhme & Falk, ESEC/FSE 2020`, `FalseCrashReducer, arXiv:2510.02185`, `Probe 1B` & `Probe 2B`):** Under Böhme & Falk's species-discovery law, additional vulnerabilities discovered by a fixed fuzz harness in fixed wall-clock time grow only logarithmically with parallel compute ($\Delta S(M) \propto \log_2 M$), while library APIs outside the harness's reachable support ($p_j = 0$) remain uncovered at any machine multiplier $M$. Synthesizing orthogonal entry-point harnesses and protocol grammars (`OSS-Fuzz-Gen`, `Fuzz4All`, `PromptFuzz`, `CKGFuzzer`, `ChatAFL`) unlocks $p_j = 0 \to p_j > 0$, whereas unconstrained bottom-up function-level C/C++ harness generation incurs an **`88.48%` pooled / `88.54%` set-stratified two-stage LLM agent-rejection rate** (`FalseCrashReducer` Tables 2 & 5: `3,583/5,080 = 70.53%` Stage-1 driver misuse + `1,696/2,785 = 60.90%` Stage-2 entry-point-infeasible crashes; `Basis: derived`).
2. **Production Power-Schedule Implementation Bugs (`llvm/llvm-project@92de736683`, `mboehme/aflfast@d1d54caf98`, `Probe 1C` & `Probe 1D`):**
   - In upstream LLVM LibFuzzer (`compiler-rt/lib/fuzzer/FuzzerCorpus.h:369–399`), `AddRareFeature` clears `IsRareFeature[Delete] = false` (`line 387`) using the `0 .. RareFeatures.size() - 1` vector slot `Delete` rather than the evicted 21-bit feature ID `MostAbundantRareFeatureIndices[0]`, and initializes `MostAbundantRareFeatureIndices` to `{RareFeatures[0], RareFeatures[0]}` (`lines 373–384`) so a strictly unique maximum at slot `0` leaves `MostAbundantRareFeatureIndices[1]` pointing to the evicted feature (`line 397`). Under default `-entropic=1` flags (`NumberOfRarestFeatures = 100`, `FeatureFrequencyThreshold = 0xFF`, `-use_counters=1`), when `150` inline 8-bit startup counters (`0, 8, ..., 1192`) tie at `Freq = 257` before discovering `Idx = 1200`, non-strict `>=` (`line 378`) selects `Delete = 149..100`, **clearing `IsRareFeature[100..149]` and blinding the `6` inline-counter features `(104, 112, 120, 128, 136, 144)`** while leaving all `50` evicted features (`800..1192`) with `IsRareFeature == true`. Re-inserting those `50` zombie features raises `S0->FeatureFreqs.size()` to `151` against `GlobalNumberOfFeatures = 101`, **underflowing 64-bit `size_t` (`lines 89–90`) to `18446744073709551566` (`2^64 - 50`)** and spiking `S0->Energy` to **`44.361420` nats (`0x1.62e42fefa39eep+5`)** vs. **`4.615570` nats (`0x1.276580b4d6a2bp+2`)** (`9.61×` inflation; `2^64 - 1` underflow with zero ties when `RareFeatures[0] != 0` is the unique maximum).
   - In `mboehme/aflfast@d1d54caf98` (`afl-fuzz.c:4802–4807, 5160, 6702`), `u32` integer division truncates `factor` to `0` before multiplying by `perf_score`, and once `fuzz_level >= 16`, `MAX_FACTOR / next_p2(fuzz)` (`32 / next_p2(fuzz)`) evaluates to `0` permanently for every seed with `n_fuzz >= 33`, triggering `goto abandon_entry` zero-execution starvation whenever `queued_paths > 10`.
3. **Static Triage Dead Code and Correlated Multi-Agent Vote Floors (`google/oss-fuzz-gen@5105d97f`, `FalseCrashReducer`, `PromptFuzz`, `CKGFuzzer`, `Hopper`, `Probe 2A` & `Probe 5`):**
   - In `google/oss-fuzz-gen@5105d97f` (`agent/semantic_analyzer.py:36, 38, 115–178, 213–217`), `SemanticAnalyzer` falsely discards genuine shallow library bugs (`lastround <= 3 -> FP_NEAR_INIT_CRASH`) and genuine `null-deref`/`signal` crashes, while **`SemanticCheckResult.FP_TARGET_CRASH` (`lines 168–172`) is 100% unreachable dead code** because `_stack_func_is_of_testing_project` (`line 214`) calls start-anchored `re.Pattern.match` (`r'in.*:\d+:\d+$'`) on frames guaranteed by `line 36` (`^\s+#\d+`) to begin with `'#'`.

4. **Cybersecurity CTF Benchmark Confounders (`Cybench@ca483c64`, `NYU_CTF_Bench@4c5744f5`, `nyuctf_agents@612190f2`, `EnIGMA`, `Probe 4`):**

   - In `EnIGMA` (`arXiv:2409.16165`, ICML 2025), interactive debugger/server tools (`IATs`) lift `Claude 3.5 Sonnet` on `pwn` (`11.36% -> 20.45%`) and `rev` (`28.85% -> 32.69%`) but **degrade `forensics` (`-2.95 pp`) and `web` (`-3.45 pp`)**, contribute `3×` less aggregate gain (`+2.06 pp`) than trajectory demonstrations (`+6.16 pp`), and co-occur with model-specific hallucinated observation "soliloquies" (**`47.5%–48.4%` on `Claude 3.5 Sonnet`** across `Cybench`/`NYU CTF` vs. **`0%` on `GPT-4 Turbo`/`GPT-4o`** and `3.6%` on `Llama 3.1 405B`) and environment leakage (`14.1%` of solves on `InterCode-CTF`, `2.7%` on `NYU CTF`).

### 2. Greybox Power Schedules, Support Walls, and Production Schedule Defects

`Basis: documentation + source + derived + execution (Probe 1)`

#### 2.1 Intra-Harness Power Schedules vs. Cross-Harness Support Walls (`Probe 1A` & `Probe 1B`)

- **Inverse-Frequency and Local-Entropy Allocation (`Probe 1A`, `Basis: derived + execution`):** On an illustrative `6`-seed corpus (`5` high-density seeds at path frequency $f(i) = 4096, s(i) = 4$, `256` mutations hitting `0` rare features, plus `1` newly discovered guard-satisfying frontier seed at $f(5) = 2, s(5) = 1$, `16` mutations dispersed evenly across $|R| = 8$ rare branches with per-exec bug probability `0.0250` vs. `0.0002`), uniform `AFL` allocates `16.67%` weight to the frontier seed (`230.77` expected executions to bug), `Entropic`'s Bayes-Laplace local Shannon entropy allocates `65.67%` (`60.65` executions, **`3.80×`** speedup), and continuous `AFLFast` Eq. (4) allocates `98.08%` (`40.77` executions, **`5.66×`** speedup).
- **Logarithmic Single-Harness Returns vs. Multi-Harness Support (`Probe 1B`, `Basis: derived + execution`):** Under an illustrative geometric tail spectrum $p_i \propto 2^{-i/8}$ across `500` reachable species plus `200` API species outside the harness's entry-point support ($p_j = 0$) at $N_{\text{base}} = 10{,}000$ executions, doubling machines $M \in \{1, 2, 4, 8, 16, 32, 64\}$ shifts the discovery front by exactly `8.0` species per doubling (`slope = 7.9999`, `R^2 = 1.000000`—an exact mathematical translational property of the chosen $2^{-i/8}$ geometric spectrum illustrating Böhme & Falk's asymptotic $\Delta S(M) \propto \log_2 M$ law), while $M = 2^{20}$ machines still cover **`0.0 / 200`** unreachable API species. Partitioning $M = 1$ (`5,000 + 5,000` executions) across two harnesses covering both subsystems discovers **`153.48`** expected species, exceeding single-harness $M = 64$ (**`132.74`** species at `640,000` executions).

### 6. Synthesized Engineering Invariants for Fuzzing and Offensive-Security Agents

`Basis: derived (synthesized from Sections 1–5)`

1. **Partition Budget Across Uncovered Entry-Point Harnesses Paired With Bug-Free Intra-Harness Schedules:** Allocate LLM synthesis budget to generating harnesses for uncovered *public entry-point subsystems* (`p_j = 0 -> p_j > 0`) while keeping floating-point pre-cap inverse-frequency (`AFLFast` Eq. 4) or patched `Entropic` (`IsRareFeature[MostAbundantRareFeatureIndices[0]] = false` + distinct top-2 index tracking) inside each harness.
2. **Gate Bottom-Up Harness Crashes With Structural Reachability and Precondition Oracles Rather Than Correlated Judge Ensembles:** Never rely on unanchored ASan regexes (`semantic_analyzer.py:214`) or $N$-way majority voting of identical-context LLM crash judges (bounded by intraclass correlation $\rho = 0.2413$ in `Probe 5A`); enforce static call-graph reachability + caller guard extraction (`CKGFuzzer`) and consumer/test slice seeding + dynamic relational invariant inference (`Hopper`, `PromptFuzz`) before crash escalation.
3. **Scope Stateful Protocol Stall Budgets Per Discovered Protocol State:** Replace campaign-wide non-resetting LLM stall counters (`ChatAFL/config.h:77` `CHATTING_THRESHOLD = 64`) with per-state-vertex adaptive backoff budgets so noisy shallow handshakes cannot starve deep session-state transitions.
4. **Enforce Modality-Scoped Tools, Stop-Sequence Observation Guards, and Zero-Oracle CTF Grading:** Expose `gdb`/interactive-socket tools selectively on binary exploitation and reverse engineering, strip whitespace in flag verifiers, mask flags greedily (`re.sub(r"\{.*\}", "{...}", flag)`), and report strict zero-oracle `pass@1`/`pass@k` separately from oracle-reset subtask metrics.
