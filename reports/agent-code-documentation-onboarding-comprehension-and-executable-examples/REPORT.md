# Code Documentation Maintenance, Repository Onboarding Retrieval, Executable Doc-Example Oracles, and Contract-Drift Laws

## Summary

Primary-source synthesis of 20 peer-reviewed software-engineering and NLP studies and preprints (2007–2026), line-level source audits across four pinned upstream repositories (`python/cpython`, `rust-lang/rust`, `OpenBMB/RepoAgent`, `evalplus/repoqa`) and three pinned replication archives (`USI-INF-Software/Conf-ReplicationPackage-ICSE2020`, `USI-INF-Software/ICPC2019-code-comment-inconsistencies`, `Ringbo/HebCup`), and a deterministic five-probe Python 3.10+ standard-library verification suite (`scripts/verify_code_docs_onboarding_doctest.py`) establish five operational laws for automated documentation maintenance, repository onboarding, and executable example verification:

1. **Behavioral Contract Drift Dominates Symbol Fabrication by Sixfold, While Surface-Overlap Metrics Penalize Truthful Updates (`DoGBench`, `Panthaplackel et al.`, `SIDE`, `HEBCUP`, `Probe 5`):** Across `1,267` audited agent documentation patches in `DoGBench` (`arXiv:2609.39909v1`), only `1.3%` are defect-free; pure symbol fabrication occurs in `6.1%`, whereas **technical inaccuracies on real interfaces**—misstating defaults, nullability, raised exceptions, upgrade compatibility, or scope—occur **`6.0×` more often (`36.6%`)**, alongside task-completion gaps (`45.5%`) and cross-surface staleness (`13.3%`). Reference $n$-gram overlap metrics (`BLEU-4`, `ROUGE`, `BERTScore`) reward leaving stale documentation untouched (`Panthaplackel et al.`, ACL 2020: untouched `Copy` achieves `46.218` `BLEU-4` at `0.000%` exact match; `Mastropaolo et al.`, ICSE 2024: `BLEU-1` odds ratio $\text{OR} = 0.9990, p = 0.6222$ on Overall Direct Assessment). Across 12 structurally distinct evolved functions (`N_eff = 12` distinct AST contracts and score vectors) in `Probe 5`, `Stale-Copy` (`0.0%` post-change contract faithfulness, `BLEU-4 = 0.402`, unpenalized modified-precision geometric mean `P_geo = 0.429`) outscores exact token-length-matched `Faithful-LengthMatched` (`100.0%` faithfulness, `BP = 1.000` on every item, `BLEU-4 = P_geo = 0.062`) by **`6.52×` on `BLEU-4`** and **`6.94×` on `BP = 1.0` `P_geo`** ($\rho = -0.734$ and $-0.761$ across the 48-candidate length-matched pool), while concise developer rewrites (`Faithful-Concise`, `100.0%` faithfulness) score `0.157` on `BP = 1.0` `P_geo` (`2.73×` below `Stale-Copy`) and `0.043` on standard `BLEU-4` (`mean BP = 0.275`, **`9.33×` total inversion**; `0/12` top-1 faithful selection under both `BLEU-4` and `P_geo` vs. `12/12` under an AST contract verifier).
2. **Stock CPython `Lib/doctest.py` Silently Passes Six Realistic Drift Classes (`0/6` Recall), Including Caller-Boundary `TypeError`s Masked Under `+IGNORE_EXCEPTION_DETAIL` (`python/cpython@436d791c`, `CPython 3.13.15`, `Probe 1`):** Default `doctest` (`optionflags=0`) misses fenced Markdown ```` ```python ```` blocks without `>>>` (`attempted = 0` via `_EXAMPLE_RE`), renamed-keyword call-binding `TypeError`s and cross-module same-shortname exceptions under `+IGNORE_EXCEPTION_DETAIL` (`_strip_exception_details`), cross-line error dumps under `+ELLIPSIS` (`_ellipsis_match`), `bool`-for-`int` return-type drift (`True == 1` in `OutputChecker.check_output`), and `SyntaxError`s inside `+SKIP` blocks (`continue` before `compile()`). Under `exec(code_obj, globs)`, Frame 0 (`exc.__traceback__`) is the runner, Frame 1 (`tb_next`) is the `<doctest>` snippet, and Frame 2 (`tb_next.tb_next`) is the first entered callee frame—which is `None` on caller-boundary `TypeError`s even when negative doctests omit exception detail (`TypeError\n`). Combining fenced-block execution, pre-`SKIP` `compile()`, `DONT_ACCEPT_TRUE_FOR_1`, single-line structural ellipsis matching, qualified exception class matching, and `tb_next.tb_next is None` call-binding rejection raises drift recall from `0/6 (0.0%)` to **`6/6 (100.0%)`** (`0/6` control false positives).
3. **Rust `librustdoc` Static `no_run` Checking Dominates Python `+SKIP`, but Exhibits Raw-String `# ` Divergence, Bare `compile_fail` Masking, and an Edition 2024 `2 -> 1 + N` Recompilation Cliff (`rust-lang/rust@342d7446`, `Probe 2`):** `librustdoc` type-checks `no_run` blocks (`--emit=metadata` standalone or non-executed `doctest_bundle` module), catching API signature drift without executing side effects, whereas `ignore` emits an empty module. However: (i) `map_line` (`html/markdown.rs:177–190`) strips `# ` pre-lexically on raw Markdown lines, producing a three-way split (`source != for_code() != for_html()`) on indented `# Section` lines inside multiline raw strings `r#"..."#` unless escaped as `## Section`; (ii) bare ```` ```compile_fail ```` passes on any non-zero `rustc` exit (`E0425` unresolved symbol masking `E0382` borrow check) unless an explicit code (`compile_fail,E0382`) is pinned; and (iii) in Edition 2024 (`MergeDoctests::Auto`), 50 clean mergeable doctests compile in **`2` `rustc` invocations** (`libdoctest_bundle` + `runner_compiler`, a `25.0×` speedup over Edition 2021's `50`), but a single compile error causes `doctest.rs:793–804` to skip `runner_compiler` (`1` failed `rustc` call) and `doctest.rs:413–428` to recompile all $N = 50$ tests standalone—spiking invocations to **`51` (`25.5×` cliff: `2 -> 1 + N`)**.
4. **Call-Edge Incremental Gating Misses `100%` of Callee Contract Drift, While Unconditional Cone Propagation Triggers `100%` Refactor Churn (`OpenBMB/RepoAgent@825d9881`, `DocAgent`, `DoGBench`, `Probe 3`):** `RepoAgent` breaks mutual-recursion cycles greedily (`get_task_manager`, leaving the first cycle member with `deps = []`) and updates existing docs only when own `code_content` changes (`travel`) or caller edge sets change (`travel2`: `set(new_callers) != set(old_callers)`), achieving **`0.0% (0/6)`** upstream stale-caller recall when callees mutate return nullability, raised exceptions, or omitted parameter defaults. Conversely, naive transitive cone invalidation yields **`100.0% (5/5)`** false-positive caller churn on internal body refactorings and explicitly pinned call-site arguments—mirroring `DoGBench`'s abstention failure (`48.6%` abstention recall on `GPT-5.6 Sol+Codex`). Tarjan strongly-connected-component (SCC) condensation paired with AST behavioral contract digests (including call-site inherited defaults) achieves **`100.0% (6/6)`** recall with **`0.0% (0/5)`** false-positive churn across callers that propagate callee exceptions and `None` unhandled.
5. **Existing Inline Comments Act as Distractors in Local Needle Retrieval Yet Aid Multi-Hop Synthesis When Verified, While `RepoQA`'s Grader Contains Three Measurement Distortions (`RepoQA`, `DocAgent`, `CodeWiki`, `RepoBench`, `Probe 4`):** Stripping natural-language comments in `RepoQA` (`Table 1`) *increases* retrieval accuracy on 13 of 15 LLMs (`+16.2 pp` on `gpt-4-turbo`, `+27.0 pp` on `deepseek-coder-33b`), whereas ablating topological dependency docs in `DocAgent` (`Table 5`) *reduces* cross-module truthfulness by `-7.89 pp` (`94.64% -> 86.75%`): local single-function behavior is directly readable from ASTs (where legacy comments inject stale lexical noise), whereas cross-module invariants require verified callee contracts. Separately, `evalplus/repoqa@ae876deb` (`compute_score.py` & `metric.py`) rejects ```` ```c++ ```` and list-indented fences at `L86–94` before tree-sitter runs (`1.000 -> 0.401` and `0.394` BLEU-4 on an exact C++ needle), evaluates only the `10` sampled needles rather than §3.2's full repository function pool $F$ (`+40.0 pp` score inflation on near-duplicate variants in $F \setminus \text{needles}$), and splits tokens solely on `re.split(r"\s+")` (`0.001` BLEU-4 on AST-identical compact Python vs. `1.000` under `tokenize` or `ast.unparse`).

### 2. Evaluation Metrics and Comment-Update Baselines: Surface Overlap vs. Contract Faithfulness

#### 2.1 Literature Evidence on Reference-Overlap Failure (`Panthaplackel et al.`, `CUP`, `HEBCUP`, `SIDE`)

`Basis: documentation + source (Ringbo/HebCup@6f52063dbf4a8c28eff013fd5b1e3dbf0fedc8a4)`

- **Untouched Stale Copy Inflation (`Panthaplackel et al.`, ACL 2020, DOI `10.18653/v1/2020.acl-main.168` / `arXiv:2004.12169v2`, Table 2 p. 7 & §6 p. 8):** On Java method-diff `@return` updates, copying the pre-edit comment verbatim (`Copy`) yields **`0.000%` exact match (`xMatch`)** yet scores **`46.218` `BLEU-4`** (`19.282` `SARI`), crushing sequence-to-sequence `Generation` (`2.083%` `xMatch`, `18.891` `BLEU-4`) and sitting within `4.5` points of reranked `Edit` (`18.433%` `xMatch`, `50.717` `BLEU-4`, `45.486` `SARI`). Even with the best model, human judges selected `None` **`55%`** of the time because local method diffs lacked cross-method repository context.
- **Single-Token Identifier Swaps Dominate JIT Updaters (`CUP`, ASE 2020, DOI `10.1145/3324884.3416581`; `HEBCUP`, ICPC 2021, DOI `10.1109/ICPC52881.2021.00013`, `Ringbo/HebCup@6f52063dbf4a8c28eff013fd5b1e3dbf0fedc8a4`):** On `CUP`'s original `9,653` pairs, neural co-attention reached `16.7%` exact match (`1,612/9,653`, `26.1%` `Recall@5`, Tables 2 & 5). After cleaning stale/noisy labels in `Ringbo/HebCup@6f52063dbf4a8c28eff013fd5b1e3dbf0fedc8a4` (`9,204` items), heuristic subtoken alignment (`HEBCUP`) achieved **`25.64%` (`2,360/9,204`)** subtoken match (`16.00% = 1,473/9,204` raw case-insensitive vs. `CUP`'s `13.18% = 1,213/9,204`) at `> 1,700×` speedup; **`96.6%`** of `CUP`'s exact matches were trivial single-token identifier renames. Under **case-insensitive single-space-collapsed** normalization (`" ".join(s.lower().split())`), `HEBCUP` vs. `CUP` scores **`19.29%` (`1,775/9,204`) vs. `17.20%` (`1,583/9,204`)** (distinct from full whitespace erasure `"".join(s.lower().split())`, which yields `25.77%` vs. `17.70%`).
- **Contrastive Code-Summary Alignment vs. $n$-Gram Metrics (`SIDE`, Mastropaolo et al., ICSE 2024, DOI `10.1145/3597503.3639174` / `arXiv:2312.15475v1`, Tables 1–2, pp. 8–9):** Principal component analysis shows `BLEU`, `ROUGE`, `METEOR`, `chrF`, and `BERTScore` collapse onto `PC1` (`55%` variance), whereas reference-free contrastive code-summary similarity (`SIDE`) captures orthogonal `PC2` (`16%` variance, loading `-0.79`). In mixed-effects ordered logistic regressions (Table 2, p. 9—where **Overall Direct Assessment** is normalized on `[1, 100]` while **Content Adequacy, Conciseness, and Fluency** are scored on `[0, 5]`, so odds ratios must only be compared within each scale):

  - *Content Adequacy (`[0, 5]`):* `SIDE` $\text{OR} = \mathbf{1.6265}$ ($t = 13.29, p < 0.0001$) vs. `BLEU-1` $\text{OR} = 0.9672$ ($p = 0.4200$) and `BERTScore-R` $\text{OR} = 1.0525$ ($p = 0.3929$).
  - *Conciseness (`[0, 5]`):* `SIDE` $\text{OR} = \mathbf{1.3844}$ ($t = 9.18, p < 0.0001$) vs. `BLEU-1` $\text{OR} = 1.0656$ ($p = 0.1575$) and `BERTScore-R` $\text{OR} = 1.0160$ ($p = 0.8770$).
  - *Fluency (`[0, 5]`):* `SIDE` $\text{OR} = \mathbf{1.2826}$ ($t = 6.94, p < 0.0001$) vs. `BLEU-1` $\text{OR} = 1.0650$ ($p = 0.2267$) and `BERTScore-R` $\text{OR} = 1.0559$ ($p = 0.4600$).

### 3. Executable Doc-Example Oracles: CPython `doctest` vs. Rust `librustdoc`

#### 3.1 CPython `Lib/doctest.py` Six Blind Spots and Traceback Frame Law (`Probe 1`)

`Basis: source (python/cpython@436d791c26de90e38ee1734a42534594f6a56e98) + execution (CPython 3.13.15 stdlib doctest in Probe 1)`

1. **Non-`>>>` Fenced Markdown Ignored (`Lib/doctest.py:613–624, 714–715`):** `DocTestParser._EXAMPLE_RE` matches only interactive `>>> ` prompts; fenced ```` ```python ```` / ```` ```py ```` blocks with broken calls or `SyntaxError`s yield `TestResults(failed=0, attempted=0)`.
2. **Caller-Boundary `TypeError` Masking Under `+IGNORE_EXCEPTION_DETAIL` (`Lib/doctest.py:350–374, 1440, 1493–1497, 1792–1795`):** `_strip_exception_details` strips everything after `:` on the exception line. When parameter `timeout` is renamed to `timeout_sec`, `connect('db.local', timeout=-1)` raises `TypeError: connect() got an unexpected keyword argument 'timeout'` at Python's call-binding boundary without entering `connect`, yet passes both `TypeError: timeout must be positive` and class-only `TypeError\n` under `+IGNORE_EXCEPTION_DETAIL`.
   - **Exact 3-Frame Traceback Law under `exec(code_obj, globs)` (`Lib/doctest.py:1440`):** Frame 0 (`exc.__traceback__`) is the runner function calling `exec()`, Frame 1 (`exc.__traceback__.tb_next`) is the top-level `<doctest>` statement (always non-`None`!), and Frame 2 (`exc.__traceback__.tb_next.tb_next`) is the first frame entered inside a callee. Therefore, checking `tb_next is None` on Frame 1 is dead (`False`); a hardened verifier must check **`exc.__traceback__.tb_next.tb_next is None`** (equivalently `snippet_tb.tb_next is None` relative to the `<doctest>` frame) to reject caller-boundary `TypeError`s even on class-only `TypeError\n` assertions (`Probe 1`: `timeout=-1` caught `1/1`, callee-body `timeout_sec=-1` passed `0/1`).
3. **Cross-Module Exception Short-Name Collision (`Lib/doctest.py:365–373`):** `_strip_exception_details` strips dotted module prefixes (`billing.errors.QuotaExceededError` $\to$ `QuotaExceededError`), silently passing when refactored code raises `storage.errors.QuotaExceededError`.
4. **Cross-Line Error Swallowing Under `+ELLIPSIS` (`Lib/doctest.py:156, 293–340`):** `_ellipsis_match` splits on `...` and matches substrings across `\n`, allowing `"Batch: ... ok\n"` to swallow `"Batch: start\nERROR: fatal checksum mismatch\nstatus: ok\n"`. Line-bounded structural matching (`len(want_lines) == len(got_lines)` without ad-hoc `"error"`/`"fatal"` substring heuristics) rejects multiline dumps while passing benign single-line outputs such as `Batch: error_rate=0.0, 42 items synced, status: ok`.
5. **Boolean/Integer Coercion (`Lib/doctest.py:1763–1767`):** Unless `DONT_ACCEPT_TRUE_FOR_1` is set, `OutputChecker.check_output` rewrites `"True\n" -> "1\n"` and `"False\n" -> "0\n"`, masking `int -> bool` return-type regressions.
6. **Uncompiled `+SKIP` Syntax Rot (`Lib/doctest.py:1420–1424, 1440`):** `DocTestRunner.__run` executes `if optionflags & SKIP: continue` *before* `compile(example.source, filename, "single", ...)`, leaving `SyntaxError`s undetected. Running `compile()` prior to honoring `SKIP` catches syntax rot statically without side effects.

#### 3.2 Rust `librustdoc` Pre-Lexical `map_line`, Fence Tiers, and Edition 2024 `2 -> 1 + N` Cliff (`Probe 2`)

`Basis: source (rust-lang/rust@342d74463af7dd3018ef6aa04dd5500c2deb5bd1) + derived + execution (Python port in Probe 2)`

1. **Pre-Lexical `map_line` Three-Way Divergence (`src/librustdoc/html/markdown.rs:149–190, 283, 826–843`):** `map_line` runs line-by-line on raw Markdown text without Rust lexing: `trimmed.startswith("##")` emits `Shown(s.replace("##", "#", 1))`; `trimmed.startswith("# ")` emits `Hidden(trimmed[2:])`; `trimmed == "#"` emits `Hidden("")`; all other lines (including `#[derive(Debug)]`) emit `Shown(s)`. Inside a multiline raw string `let md = r#"\n  # Section\nbody\n"#;`, raw source contains `"\n  # Section\nbody\n"`, compiled `for_code()` (`L842`) receives `"\nSection\nbody\n"` (both `# ` and leading indentation stripped), and HTML `for_html()` (`L283`) returns `None`, **deleting the line completely** (`r#"\nbody\n"#`). Escaping as `## Section` restores exact parity (`"\n  # Section\nbody\n"`) between rendered HTML and compiled code. Separately, hidden `# ` lines can inject compensating bindings (`# let auth_ctx = "secret";`) invisible to HTML readers.
2. **Four-Tier Fence Semantics & Bare `compile_fail` Masking (`html/markdown.rs:919–939`, `doctest/runner.rs:226–286`, `doctest.rs:636–640, 840–910`):**
   - `ignore` (`runner.rs:228`) skips standalone compilation (`0` `rustc` calls) or emits an empty `pub mod __doctest_{id} {}` in merged bundles, masking arbitrary syntax and type rot.
   - `no_run` compiles with `--emit=metadata` standalone (`doctest.rs:639`) or inside `doctest_bundle` while substituting `Ok::<(), String>(())` in the runtime harness (`runner.rs:275`), catching type/borrow drift (`E0061`) with zero side effects.
   - Bare `compile_fail` (`doctest.rs:845`) passes on *any* non-zero `rustc` exit status, falsely passing when a symbol rename triggers `E0425` before borrow checking (`E0382`) ever runs; specifying `compile_fail,E0382` (`L846–856`) enforces `error[E0382]` in compiler output.
3. **Edition 2024 Merged-Doctest `2 -> 1 + N` Recompilation Cliff (`doctest/make.rs:173–187`, `doctest/runner.rs:179–212`, `doctest.rs:371–428, 726–805`):**
   - `ScrapedDoctest::can_be_merged` (`make.rs:173–187`) opts out `compile_fail`, `test_harness`, `standalone_crate`, and (under `MergeDoctests::Auto` in Edition 2024) `has_global_allocator`, `#![...]` crate attributes, and `$crate`-referencing macros.
   - For $N = 50$ mergeable doctests, Edition 2021 (`MergeDoctests::Never`) spawns **`50` `rustc` processes**. Clean Edition 2024 (`MergeDoctests::Auto`) spawns **`2` `rustc` processes** (`25.0×` speedup: `compiler.spawn()` at `doctest.rs:726` for `libdoctest_bundle_2024.rlib` + `runner_compiler.spawn()` at `L796` for the binary harness, including when all mergeable tests carry `ignore`).
   - When **any** merged doctest fails to compile (`!status.success()` at `doctest.rs:793`), `runner_compiler.spawn()` is **skipped** (`1` failed `rustc` call), and `doctest.rs:413–428` pushes all $N$ mergeable tests onto `standalone_tests` to isolate per-test diagnostics—spawning **`1 + N = 51` `rustc` processes (`25.5×` cliff: `2 -> 51`)**.

### 4. Repository Onboarding Retrieval, Comment Paradox, and Call-Graph Drift Propagation

#### 4.1 Onboarding Benchmarks & Resolving the `RepoQA` vs. `DocAgent` Comment Paradox

`Basis: documentation + derived`

- **Cross-File Retrieval Bottleneck (`RepoBench`, Liu, Xu, & McAuley, ICLR 2024, `arXiv:2306.03091v2`, Tables 1–2, pp. 5–6):** Mean pipeline prompts span `44,028` (Python) and `139,406` (Java) tokens. On cross-file Hard retrieval (`XF-F` / `XF-R`, `acc@1`), **Python Hard** scores `Random 6.42%–6.44%`, `CodeBERT 6.56%–7.03%`, `Jaccard 10.01%–11.38%`, `UniXcoder 17.70%–20.05%`, whereas **Java Hard** drops to `Random 5.59%–5.64%`, `CodeBERT 5.92%–6.07%`, `Jaccard 7.15%–9.22%`, `UniXcoder 10.79%–15.10%`.
- **Long-Context Needle Retrieval & Comment-Free Gain (`RepoQA`, Liu et al., `arXiv:2406.06025v1`, Tables 1–2, pp. 4, 8):** Across `500` Searching Needle Function tasks (`50` repos $\times$ `10` needles, `16k` context, `0.8` BLEU-4 threshold), `claude-3-opus`, `gemini-1.5-pro`, and `gpt-4o` tie at **`90.6%`**. C++ is the lowest-scoring language among the **top-6 frontier models** (`79%–83%` on top 4 vs. `85%–97%` elsewhere), while mid-tier/open models often bottom out on TypeScript (`gpt-4-turbo` `.ts = 55%` vs. `.cpp = 79%`; `Mixtral-8x22B` `.ts = 55%` vs. `.cpp = 67%`) or Rust (`deepseek-coder-33b` `.rs = 23%` vs. `.cpp = 44%`). Crucially, **Comment-Free (`CF`)** code stripping *improves* accuracy on 13 of 15 models (`gpt-4-turbo` `76.4% -> 92.6%`, `deepseek-coder-33b` `48.4% -> 75.4%`, `gpt-4o` `90.6% -> 93.2%`), while `# Line Number` padding collapses `gemini-1.5-flash` (`90.0% -> 54.2%`).
- **Topological Multi-Agent Synthesis (`DocAgent`, Yang et al., `arXiv:2504.08725v3`, Tables 3 & 5, pp. 7–8; `CodeWiki`, Hoang et al., `arXiv:2510.24428v6`, Table 1 p. 7 & §5.4 p. 9):** `DocAgent`'s Navigator + Reader/Searcher/Writer/Verifier DAG lifts AST Entity Existence Ratio from `45.04%` (`FIM-CL`) and `61.10%` (`Chat-GPT`) to **`95.74%`** (`DA-GPT`) and **`88.17%`** (`DA-CL`), and Completeness from `0.314`/`0.815` to **`0.934`**; randomizing topological order (`DA-Rand-GPT`, Table 5) drops Truthfulness **`94.64% -> 86.75%` (`-7.89 pp`)**. On `CodeWikiBench` (`7` repos, `86K–1.45M` LOC), hierarchical `CodeWiki` reaches **`68.79%`** vs. closed-source `DeepWiki` (`64.06%`, `+4.73 pp`), `deepwiki-open` (`50.05%`), and `OpenDeepWiki` (`47.13%`), with C/C++ hardest (`53.24%` vs. `79.14%` scripting).
- **Resolution of the Comment Paradox (`derived`):** In single-function retrieval (`RepoQA`), target semantics are locally observable in `< 2 KB` of AST, while legacy comments inject stale vocabulary (`45%` of `iComment` mismatches) and lexical distractors matching neighboring functions. In multi-hop repository synthesis (`DocAgent`, `CodeWiki`, `Panthaplackel` human study), callees impose non-local invariants invisible in a caller's AST. Agents must therefore treat legacy comments as **untrusted hypotheses** checked against live ASTs while propagating **AST-verified** dependency contracts bottom-up.

### 5. Operational Rules for Documentation Agents and CI Harnesses

`Basis: derived (synthesized from Sections 1–4)`

1. **Gate Edits on Behavioral Contract Digests (`DoGBench` + `Probe 3`):** Abstain when `contract_digest` and user-visible CLI/config/schema behavior are invariant; propagate updates to upstream callers when public signatures, return nullability, unhandled raised exceptions, or call-site-omitted defaults change (filtering out `try ... except`-caught exceptions and coalesced `None` values).
2. **Enforce Pre-Drafting Evidence & Cross-Surface Enumeration (`DoGBench`):** Read controlling implementation, schema/config, and tests before drafting; enumerate all affected surfaces (docstrings, CLI reference, tutorials, migration notes); never treat zero doc hits as justification to abstain; and verify end-to-end reader workflows.
3. **Harden Python Doctest Gates (`Probe 1`):** Execute ```` ```python ```` / ```` ```py ```` fences without `no_run`/`skip` (failing CI if `attempted == 0` on documentation containing executable Python code fences), enable `DONT_ACCEPT_TRUE_FOR_1`, run `compile(..., "single")` before `+SKIP`, enforce single-line ellipsis bounds, ban `+IGNORE_EXCEPTION_DETAIL` in favor of qualified exception classes + message checks, and verify `exc.__traceback__.tb_next.tb_next is not None` under `exec()` so caller-boundary `TypeError`s never pass negative tests.
4. **Harden Rust `rustdoc` Gates (`Probe 2`):** Prefer `no_run` over `ignore`; require explicit error codes (`compile_fail,E0382`); escape literal `# ` lines inside multiline raw strings (`r#"..."#`) as `## `; audit hidden `# ` setup lines; and scope iterative Edition 2024 repairs with `cargo test --doc -- <item>` (or `cargo check` first) to avoid the `2 -> 1 + N` (`25.5×` at $N = 50$) recompilation cliff.
5. **Use Tarjan SCCs, Non-Destructive Git Reads, and AST Entity/Contract Checks (`DocAgent` + `Probe 3 & 5`):** Schedule synthesis bottom-up over Tarjan SCCs, read historical blobs via `git show <rev>:<path>` (never in-place working-tree renames), and evaluate updates via AST symbol-existence + contract verification rather than `BLEU`/`ROUGE`.

## Boundaries

- **Executable doctests are a soundness floor, not a prose completeness oracle (`known not to apply`):** Green hardened doctests verify only executed/type-checked code paths; as `DScribe` (`79.2%` of documented exception units untested) and `DoGBench` (`36.6%` prose technical inaccuracies on upgrade scope/defaults, `13.3%` cross-surface staleness) establish, passing examples do not prove surrounding prose claims or sibling reference pages are accurate.
- **Exception-catching and null-coalescing wrappers in `ContractDigest` (`known not to apply` without handler-aware extension):** `Probe 3`'s `compute_transitive_contract_digests` takes unconditional set unions of `effective_raises` and boolean ORs of `effective_nullable`. Its `0.0%` (`0/5`) false-positive churn bound holds for callers that propagate callee exceptions and `None` unhandled; intermediate wrappers that catch callee exceptions (`try ... except`) or coalesce `None` to a non-null fallback require intraprocedural handler/branch suppression to avoid conservative false-positive caller invalidations.
- **Flat call-edge port of `RepoAgent` `get_task_manager` (`not examined` in `Probe 3`):** `Probe 3` ports the flat non-special call-edge core of `doc_meta_info.py:637–696` and exact `load_doc_from_older_meta` (`L752–805`), omitting hierarchical `x.depth` pre-sorting (`L633`), `item.children` containment, and `special_reference_type` parameter-default secondary cycle breaking (`L647–672`).
- **Live upstream toolchain and LLM pipeline execution (`not examined`):** `rust-lang/rust@342d7446...`, `OpenBMB/RepoAgent@825d9881...`, and `evalplus/repoqa@ae876deb...` were verified by line-level source audit and deterministic Python ports (`Probes 2–4`), not by compiling `librustdoc` from `342d7446...` or executing live OpenAI/vLLM runs.
- **`nltk_corpus_bleu` short-hypothesis boundary (`unsupported` below 4 tokens):** `scripts/verify_code_docs_onboarding_doctest.py` enforces `len(hypothesis) >= 4` (`>= 5` across all `Probe 4` and `Probe 5` inputs), matching upstream `nltk.translate.bleu_score` + `SmoothingFunction().method4` identically on its valid BLEU-4 domain; hypotheses with `< 4` tokens are rejected by assertion rather than emulating upstream NLTK's unnormalized `Fraction(0, 0)` zero-denominator state.
- **Closed-access publisher sub-table breakdowns (`not examined`):** For paywalled articles paired with open replication packages (`Aghajani et al.` ICSE 2019/2020, `Wen et al.` ICPC 2019, `Lin et al.` ICPC 2021), quantitative claims are restricted strictly to counts verified directly in the pinned replication archives and official publisher metadata.
- **Neighboring software-engineering artifact classes (`not examined`):** Commit-message rationale quality, local inline-comment cohesion rubrics, standalone architectural specification design, and general prose readability indices are outside this report's scope.
