# Primary source attribution

The Islaris files/fragments are from rems-project/islaris at the immutable
revision in upstream-fragments-manifest.json, under its BSD two-clause source
license; retained proof fragments include the original full copyright and
license header. The coq-sail and sail-riscv opam metadata retain their upstream
package authors and license declarations (BSD three-clause/BSD3 respectively).
Newly retrieved opam metadata and source-selection coordinates are retained in
ISLARIS-primary-files.json with original attribution/license fields.

Fragment line ranges refer to the original complete upstream file. Inserted
range comments identify omitted sections. No fragment is presented as an
independently compilable theorem or modified upstream proof. Source evidence
and embedded upstream commands do not authorize execution.
