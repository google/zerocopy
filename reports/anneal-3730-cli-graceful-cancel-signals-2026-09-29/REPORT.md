# R22: selected CLI cancellation signals and same-directory recovery

Observed 2026-09-29 with pinned local Charon, one-shot Aeneas, Lake and Lean CLIs. `support/probe.py` creates tiny private fixtures and serially runs seven active-gate cases. `support/results.json.gz` preserves every command, elapsed time, stdout/stderr, PID, process-group membership and status, signal timeline, raw `lsof` output, advisory `flock` probe, artifact inventory and hash, retry, and fresh consumer. `python3 support/check.py` validates the retained evidence without rerunning CLIs.

| Active barrier | Graceful first signal | SIGKILL control | Same-directory recovery |
| --- | --- | --- | --- |
| Charon after JSON LLBC and before Postcard FIFO | SIGINT; controller exit −2; controller and `charon-driver` gone from immediate process-group snapshot. | Exit −9; same descendant result. | Retained parseable partial JSON, removed only the blocked FIFO, retried in the **same output directory**; both JSON and Postcard present, with Postcard independently parsed by Charon. |
| Aeneas after `Types.lean` and before `Funs.lean` FIFO | SIGTERM; exit −15; no group member in immediate post-signal snapshot. | Exit −9; same descendant result. | Retained `Types.lean`, removed only the blocked FIFO, retried in the **same output directory**; generated modules compiled and a fresh Lean consumer proved `signal_probe.inc 0 = .ok 1`. |
| Lake build, with Lean child inside `run_tac` after A's OLean | SIGINT; Lake exit −2; Lake and Lean child gone from immediate group snapshot. | Exit −9; same descendant result. | Retained A's OLean, released the tactic gate, retried in the **same Lake directory**; B's OLean and a fresh consumer proof of `chosen = 8` succeeded. |

An additional **synthetic supervisor control** launches actual Aeneas with SIGINT inherited as ignored. Both supervisor and CLI remained live after SIGINT; the bounded policy escalated to SIGTERM and both disappeared from the immediate group snapshot. The retry used unsupervised Aeneas in the same output directory and passed the Lean consumer. This tests the experiment's escalation branch under deliberately modified signal disposition. It does not characterize ordinary Aeneas SIGINT behavior or an Anneal supervisor.

Raw `lsof` snapshots show open pipes at all selected barriers; the code also records descriptor paths and lock columns. A nonblocking exclusive `flock` on each selected completed artifact succeeded during the gate and after termination. That only shows no competing **advisory flock** on those particular files at the sampled instants; it does not rule out other locks, unpublished temporary files, or a later orphan. The signal policy waits up to one second between steps and can escalate SIGINT→SIGTERM→SIGKILL. In the unmodified direct CLI cases, the first signal sufficed. The immediate process-group snapshots had no members after exit in these cases.
