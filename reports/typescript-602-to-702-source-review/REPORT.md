## Findings

At 6.0.2, R576's source inspection identified `LanguageServiceHost` and immutable script snapshots as a host-supplied semantic context, and `ProjectService` as the owner of additional editor/project state. Those are **old-pin source findings**, not 7.0.2 facts. The [TypeScript team's 7.0 announcement](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/) calls 7.0 a native Go port and says 7.0 shipped without a stable programmatic API, recommending side-by-side use of the 6.0 API for API-dependent tools. This is first-party release context; it is not a claim that 7.0.2 has equivalent host hooks or runtime behavior.

At the original 7.0.2 native commit, [`internal/project/project.go`](https://github.com/microsoft/typescript-go/blob/2bd066d87f5bafd315be9f40889d0a60b9e58e0b/internal/project/project.go), [`internal/lsp/server.go`](https://github.com/microsoft/typescript-go/blob/2bd066d87f5bafd315be9f40889d0a60b9e58e0b/internal/lsp/server.go), and [`cmd/tsgo/lsp.go`](https://github.com/microsoft/typescript-go/blob/2bd066d87f5bafd315be9f40889d0a60b9e58e0b/cmd/tsgo/lsp.go) show a Go project/LSP code path. These inspected files are relevant entry points, but a complete mapping of file/version/snapshot authority, project selection, configuration, cancellation, generated outputs and public API availability was not checked. No claim-specific continuity or contradiction of the entire frozen paragraph is asserted. The comparison is **source-unresolved** rather than a release-date inference.

The original R576 report's conditional Anneal advice remains analysis at its cited Anneal design commit. This review neither adopts that advice as policy nor verifies an Anneal host or backend against TypeScript 7.0.2. Source, runtime, and product results are recorded separately in the matrix.
