# Lifting Rust Mutable Borrows into Pure Proof Obligations: Prophecy Variables, Backward Functions, and Bidirectional Lenses

## Summary

Deductive verification of Rust without global heap separation logic hinges on lifting exclusive mutable references (`&mut T`), nested reborrows, disjoint sub-place splits, loops, and stateful iterators (`core::slice::IterMut<'a, T>`) into pure functional proof obligations. Across production verifiers, three semantic encodings dominate:

1. **Prophecy variables (`*x` / `^x` + `Resolve`)**—introduced in RustHorn (`10.1145/3462205`) and Iris ghost prophecies (`10.1145/3371113`), and deployed in Creusot/Pearlite (`creusot-rs/creusot@601d97891bb0bc0b569686cc946ef4980560b5d8`) and RefinedRust (`10.1145/3656422`)—model `&mut T` as a `(current, final)` pair, overwrite the borrowed owner *at borrow creation* with the nondeterministic final value `^x`, and assume `*x == ^x` when the borrow resolves. Prophecies yield concise relational specifications (`Produces` on `IterMut`) with zero signature arity growth, but soundness either places `rustc_borrowck` inside the trusted computing base (TCB) (Creusot, RustHorn) or requires step-indexed ghost state in Iris (RefinedRust), and prophecy quantifiers create witness-instantiation friction in tactic-restricted interactive kernels.
2. **Backward functions and region-group continuations**—deployed in Charon/Aeneas (`AeneasVerif/aeneas@d86aa34c75fd036ac139eb6e65da1cacc5492d0f`)—translate a borrow-returning call or lifetime group `'a` into a forward value paired with a higher-order continuation `back : B → A` (`Result (B × (B → A))`) invoked when `'a` ends, synthesizing recursive backward continuations at loop fixed points. Backward functions eliminate quantifiers on straight-line code, but nested higher-order closures obstruct first-order kernel definitional reduction (`whnf`/`isDefEq`), block mutable-borrow-carrying structs (`IterMut`), and place an OCaml symbolic interpreter in the TCB unless paired with per-program translation validation.
3. **First-order bidirectional lenses with permission tries and loan-graph DAGs**—realized in Anneal's untrusted `theory/Anneal/PureLift` (`joshlf/anneal@c131b320eeeb26ef692e5afd5ec8db49ee518613`), building on lawful partial lenses (`10.1145/1232420.1232424`, `10.1145/1328438.1328487`)—keep active borrows in a computable first-order `SymState Val` (`PermTree` sub-place tries + serialized `BackTarget` trees + `LoanPhase.spatialPinned` byte-view pinning) where every safety or borrow violation evaluates to `EvalOutcome.fail` (`False`). Under Lean 4 (`v4.34.1`) 3-axiom, closed-tactic, zero-TCB rules, first-order loan-graph lenses preserve fast `whnf`/`isDefEq` reduction and compose with localized spatial separation logic (`SpatialPin`), while Pearlite-style `(current, final)` postconditions can compile as boundary sugar over `FuncOut.mutFinals`.

## Applicability

This report compares concrete upstream revisions and peer-reviewed formalisms across four axes: (a) soundness bridges over small-step Mid-level Intermediate Representation (MIR) semantics, (b) Day-2 proof modularity on reborrows, slice splits, loops, and `Iterator` state machines, (c) heterogeneous composition with `unsafe` raw pointers, `UnsafeCell`, `MaybeUninit`, and unwinding, and (d) mechanization scaling in Lean 4 (`leanprover/lean4@5045d0056413266e57c625dcd7c365b10e377c52`, `v4.34.1`).

## Findings

### 1. Semantic Taxonomy: Where Future Writes Live in Time and State

`Basis: source + normative + derived`

In operational MIR (`Trusted/MirSemantics.lean`), `let r = &mut x.f; *r = v;` mutates `x` in place via an aliased location `(AllocId, Offset)`, whereas pure functional logics have only immutable values. The three encodings differ in *when* owner `x` receives its updated sub-value and *how* the pending obligation is represented:

| Dimension | Prophecy Variables (RustHorn, Creusot, RefinedRust) | Backward Functions (Charon / Aeneas) | Loan-Graph Optics + Permission Tries (PureLift) |
| :--- | :--- | :--- | :--- |
| **Representation of `r: &'a mut T`** | Pair `(current: T, final: T)` (`*r`, `^r`) + optional ID for final-reborrow inheritance | Erased in pure code: forward value `r_cur : T` + continuation `back : T → Owner` | First-order handle `Val` (`encodeRef lid path`) indexing `LoanEntry` `(phase, PlaceCell, BackTarget)` |
| **When owner `x` is updated** | **At borrow creation** (`x.f := r.final` immediately via clairvoyant assignment) | **At region `'a` termination** (`let x' = back r_final` in lifetime topological order) | **At `endLoan` / `endRegionGroup`** (`evalBackVal` / `putPath` + `PermTree` unlock) |
| **How lifetime end is enforced** | Logical assumption `resolve(r)` (`*r == ^r`) when `r` dies | External symbolic borrow checker (`InterpBorrows`) places backward calls | Total check in `SymState`: conflicts/leaks evaluate to `EvalOutcome.fail` (`False`) |
| **Borrow-returning call `choose<'a>(c, &'a mut x, &'a mut y) -> &'a mut T`** | Postcondition `(c → *res == *x ∧ ^res == ^x ∧ *y == ^y) ∧ (¬c → ...)` | Returns `(res : T) × (back : T → T × T)` closure | `BackTarget.choice cond (.direct x []) (.direct y [])` or `.lensCall` step list |
| **Borrow-carrying structs (`IterMut<'a, T>`)** | Native in logic (`Seq<&'a mut T>` via `#[trusted] View` + `Resolve`) | Rejected in pure ADT translation (`SymbolicToPureTypes.ml:295-300`) | Supported via `ValAlgebra.remapRefInVal` for tuples; slices need `SpatialPin` sub-splits |
| **Soundness TCB without Iris** | Trusts `rustc_borrowck` + drop placement (Creusot, RustHorn) | Trusts Charon + OCaml symbolic interpreter (`Aeneas`) | **0-TCB**: untrusted `theory/` proved against `Trusted.MirSemantics` |

### 2. Prophecy Variables (`*x` / `^x` and `Resolve`) in RustHorn, Creusot, and RefinedRust

`Basis: normative + source`

In RustHorn (`10.1145/3462205`) and Creusot (`10.1007/978-3-031-17244-1_6`), `b: &mut T` denotes `(b.current, b.final)`, written `(*b, ^b)` in Pearlite. Inspecting `creusot/src/backend/program.rs:1267-1369` at `601d97891bb0bc0b569686cc946ef4980560b5d8` shows the exact translation of `StatementKind::MutBorrow(bor_kind, lhs, rhs)`:

1. `projections_to_expr` (`lines 1274–1322`) decomposes `rhs` into a read expression `rhs_rplace` and a functional reconstruction closure `rhs_constr`.
2. Creusot emits a Coma call to `MutBor.borrow_mut` (or `MutBor.borrow_final` when `bor_kind` is `BorrowKind::Final(deref_index)`), binding `_bor` (`ret_ident`) with `_bor.current == rhs_rplace` and unconstrained `_bor.final` (`reassign`, line 1328).
3. When `rhs_ty` carries a non-trivial type invariant `inv`, Creusot emits `Check(inv(rhs_rplace))` and `Assume(inv(_bor.final))` (`lines 1331–1347`).
4. **Immediate prophetic writeback (`lines 1367–1368`)**: `let new_rhs = rhs_constr(&mut istmts, reassign); istmts.push(IntermediateStmt::Assign(rhs.local, new_rhs));` overwrites `rhs.local` with `_bor.final` *at the borrow site*, before any write through `lhs`.
5. **Resolution**: When `lhs` leaves scope, Creusot assumes `resolve(lhs)` (`creusot-std/src/resolve.rs:9-64`), equating `*lhs == ^lhs` (or invoking `Resolve::resolve` linked to structural resolution via `resolve_coherence`, `resolve.rs:23-33`).

**Reborrow Quantification and `BorrowKind::Final`.** Under naive RustHorn lowering, every reborrow `let r2 = &mut (*r1).f;` mints a fresh prophecy `r2_final`, updates `r1.current.f := r2_final`, and defers `r1.current == r1.final` until `r1` dies—chaining fresh quantified variables on every loop iteration. Creusot mitigates this with backward dataflow pass `NotFinalPlaces` (`creusot/src/analysis/not_final_places.rs:27-160`), marking dead-parent reborrows as `BorrowKind::Final(deref_index)` (`creusot/src/translation/fmir.rs:78-87`) so `MutBor.borrow_final` (`program.rs:1299-1309, 1355`) inherits a deterministic child prophecy ID (`borrow_generated_id`). However, `HPlace::ambiguous` (`not_final_places.rs:102-104`) returns `true` whenever a path contains `HProjectionElem::Index`: dynamic slice indexing cannot inherit final borrows and falls back to quantified `resolve_elswhere` frame conditions (`creusot-std/src/std/slice.rs:164-186`).

**Soundness Bridge.** Eagerly assigning `rhs.local := rhs_constr(_bor.final)` is unsound if any alias reads `rhs.local` while `lhs` is active. Creusot and RustHorn discharge non-aliasing by trusting `rustc_borrowck` inside the TCB. RefinedRust (`10.1145/3656422`, building on Jung et al., `10.1145/3371113`) achieves a foundational bridge in Rocq/Iris over Caesium using exclusive ghost prophecy tokens $\mathsf{Proph}(p, \vec{v})$, at the cost of mechanizing an impredicative step-indexed separation logic (`iProp`) over operational semantics.

### 3. Backward Functions and Region-Group Continuations in Charon and Aeneas

`Basis: normative + source`

Aeneas (`10.1145/3547647`, `10.1145/3674640`) eliminates prophetic variables by turning lifetime termination into pure continuation functions. Charon (`AeneasVerif/charon@9e193f0317dacc822cc864c1798b117c70dcf7df`) lowers MIR to LLBC, and Aeneas (`AeneasVerif/aeneas@d86aa34c75fd036ac139eb6e65da1cacc5492d0f`) symbolically executes LLBC over loan abstractions before generating pure definitions:

1. **Reference erasure and merged forward/backward pairs**: `SymbolicToPureTypes.ml:173` translates `TRef (_, rty, _)` directly to `translate span rty`. Lifetime groups (`RegionGroupId`, `SymbolicToPureCore.ml:154-216`) become backward continuations returned alongside forward values: in `backends/lean/Aeneas/Std/Slice.lean:283-295`, `Slice.index_mut_usize` has signature `Slice α → Usize → Result (α × (α → Slice α))`, returning `ok (x, Slice.set v i)`.
2. **Total-fallback hazard in `split_at_mut`**: In `Aeneas/Std/Slice.lean:740-755`, `core.slice.Slice.split_at_mut` returns `Result (((Slice T) × (Slice T)) × (((Slice T) × (Slice T)) → Slice T))`. Because `Slice T` enforces `s.val.length ≤ Usize.max`, a total closure `back : (Slice T × Slice T) → Slice T` cannot concatenate arbitrary `s0'.val ++ s1'.val` without proving the sum fits in `Usize.max`. Aeneas guards `back` with `if h1 : s0'.length = s0.length ∧ s1'.length = s1.length then .from (s0'.val ++ s1'.val) ... else s` (`lines 748–751`)—silently returning the *unmutated* slice `s` on length mismatch and pushing length preconditions into `split_at_mut.spec` (`lines 783–785`).
3. **Loop backward synthesis and expressiveness limits**: On loops that reborrow across iterations, `InterpLoops.ml:78-250` computes a symbolic borrow fixed point `fp_ctx` (`eval_loop_symbolic_apply_loop`) and synthesizes recursive loop backward continuations (`ELoop (abs.abs_id, loop_id)`). However, `SymbolicToPureTypes.ml:295-300` aborts on `"ADTs containing nested mutable borrows are not supported yet"`, `InterpLoops.ml:182` rejects nested-loop breaks, `README.md:132-139` documents that instantiating type parameters `T` with `&mut U` and all `unsafe` blocks are unsupported.

### 4. Bidirectional Lenses, Permission Tries, and Loan-Graph DAGs in Anneal `PureLift`

`Basis: source + derived`

Anneal's `theory/Anneal/PureLift` (`joshlf/anneal@c131b320eeeb26ef692e5afd5ec8db49ee518613`) combines partial bidirectional lenses (`10.1145/1232420.1232424`, `10.1145/1328438.1328487`) with an explicit first-order loan graph engineered for Lean 4 kernel reduction:

1. **Lawful Partial Lenses and Commutation (`Lens.lean:86-614`)**: `Lens S A` (`get : S → Option A`, `put : S → A → Option S`) satisfies `get_put`, `put_get`, and `put_put` (`LawfulLens`, closed under `Lens.comp_lawful`). `ValAlgebra Val` (`lines 295–408`) adds two multi-place laws: sibling preservation `getField_setField_other` (`f ≠ g`) and **whole-value commutation** `setField_setField_comm` (`f ≠ g → setField f s a = some s1 → setField g s1 b = some s2 → ∃ s1', setField g s b = some s1' ∧ setField f s1' a = some s2`), from which `putPath_putPath_diverging_comm` (`lines 544–614`) proves that disjoint sub-place writebacks commute regardless of loan-release order.
2. **Loan-ID Permission Tries (`PermTree.lean:40-549`)**: Each local and loan slot holds `PlaceCell Val` (`val : Val`, `perm : PermTree`), where `PermTree` is `.unborrowed | .shared (List LoanId) | .mutLocked LoanId | .mutJoined (List LoanId) (List LoanId) | .split (List (SubPath × SubPerm))`. Explicit `LoanId` sets make `releaseLoanPerm` path-free and idempotent, while `unionPerm` (`line 472`) conservatively preserves active loans from both arms of symbolic `if`/`else` joins.
3. **Serialized `BackTarget` Trees and Fail-Closed Outcomes (`LoanGraph.lean:52-623`)**: Writeback targets are first-order pre-order lists `List (BackTargetStep Val)` (`.rootParam`, `.direct owner path`, `.choiceJoin cond`, `.lensCall targets backFn`, `.regionOut groupId outIdx`), evaluated via `List.foldr` (`evalBackVal`, `lines 462–515`) with multi-region outlives ordering enforced via `RegionGroupEntry.requiredChildren` and `regionDeposits` (`lines 587–623`). Unlike Aeneas's `else s` fallback, any `backFn` returning `none`, arity mismatch, aliasing conflict, or leaked loan yields `EvalOutcome.fail`, where `HoldsFnSpec .fail post = False` (`Lens.lean:94-101`).
4. **Operational Bridge (`Adapter.lean`, `MirBridge.lean`)**: `MirBridge.lean` instantiates `ValAlgebra Trusted.MirSemantics.Val` (`mirValAlgAt d`, proving all five lens/commutation laws over `Val.tuple` at `lines 425–618` and encoding handles in provenance-tagged `Val.bytes` at `lines 710–755`), transferring proofs to `Anneal.MirWp` and `Trusted.Correspondence` (`lean-miri`) with zero `trusted/` changes. While straight-line bodies lift automatically via `liftStraightLineMir`, multi-block borrow plans currently pair `evalFnValue` with a per-body `MirRunsTo` simulation witness `hSim` (`MirBridge.lean:58-62`).

### 5. Stress-Test Comparison: Loops, Slice Splits, and `core::slice::IterMut`

`Basis: source + derived`

Upstream `core::slice::IterMut<'a, T>` (`rust-lang/rust@8144389c895da997dbdecaa635e41d6a50be6ffd`, `library/core/src/slice/iter.rs:192-203`, `macros.rs:157-192`) stores `{ ptr: NonNull<T>, end_or_len: *mut T, _marker: PhantomData<&'a mut T> }`. In `IterMut::next(&mut self) -> Option<&'a mut T>`, ZSTs decrement a provenance-free length in `end_or_len` (`without_provenance_mut(len.unchecked_sub(1))`), while non-ZSTs test `ptr == transmute::<*mut T, NonNull<T>>(end_or_len)`, advance `self.ptr = ptr.add(1)`, and yield `Some(ptr.as_mut())`. This combines raw-pointer erasure, ZST provenance punning, and lifetime extension (`&'b mut IterMut<'a, T>` yielding `&'a mut T` where `'a` outlives `'b`):

- **Creusot (`creusot-std/src/std/slice.rs:736-888`, TACAS 2023 `10.1007/978-3-031-30820-8_9`)**: Cannot verify `IterMut::next`'s raw-pointer body; axiomatizes `#[trusted] impl View for IterMut` (`ViewTy = &'a mut [T]`) and `extern_spec!` on `next`. For *clients*, prophecies excel: `produces(self, visited, tl)` is `self@.to_mut_seq() == visited.concat(tl@.to_mut_seq())`, and early `break` resolves `tl` (`*tl@ == ^tl@`), framing unvisited suffix elements with zero backward recursion.
- **Aeneas (`Aeneas/Std/Slice.lean`)**: Rejects `IterMut` in pure translation (`SymbolicToPureTypes.ml:295-300`); `Slice.lean` provides `index_mut_usize`, `split_at_mut`, `mapM`, and `fill`, requiring `iter_mut()` loops to be rewritten to index loops or modeled via $O(N)$-nested backward closures.
- **PureLift (`BlockCfg.lean:75-153`, `SpatialPin.lean`)**: Whenever yielded element borrows die inside each loop iteration (`for x in s.iter_mut() { *x = f(*x); }`), `IterMut` models cleanly as a first-order cursor `(lid_slice, idx, len)` acquiring and ending `[idx]` on `lid_slice` per step—verified via `runWhileFlowSteps_cutpoint_sound` with flat invariants and zero closures or prophecies. When borrows escape across iterations (`split_first_mut`), `PermTree.split` locks disjoint indices simultaneously and commutes writebacks via `putPath_putPath_diverging_comm`. Verifying `core::slice::IterMut::next`'s *internal* `NonNull<T>` body at 0-TCB requires extending `SpatialPin` with sub-block splitting (relaxing `blk.activeSubSplits == 0` in `SpatialPin.lean:168, 276`).

### 6. Heterogeneous Composition: Raw Pointers, `UnsafeCell`, `MaybeUninit`, and Unwinding

`Basis: source + normative + derived`

1. **Localized Spatial Pinning (`SpatialPin.lean:202-294`)**: Prophecies break when raw pointers alias a borrowed owner or write `MaybeUninit` uninitialized bytes (`^x : T` presupposes valid `T` values). PureLift's `freezeToSpatialInState` transitions an unborrowed `.activeMut` loan `lid` to `LoanPhase.spatialPinned bid codec`, exporting `List (CellVal Val)` (`.init v`, `.uninit`, `.rawByte UInt8`) while keeping `lid.target` intact and leaving all unpinned locals pure (zero spatial framing on pure state). `reabsorbFromSpatialInState` checks `!hasUninitCell`, decodes via the original `pinnedCodec` (`spatial_roundtrip_and_codec_binding_test`, `lines 330–355`), and blocks fabricated borrow handles (`!replaceableVal`, `lines 283, 560–580`).
2. **Tree Borrows Protectors & Unwinding (`Miri/TreeBorrows/Permissions.lean:18-112`, `Miri/Interpreter/Unwind.lean`)**: Under Tree Borrows (`10.1145/3735592`), protected `&mut T` arguments turn `.Disabled` (not `.Frozen`) on foreign reads (`Permissions.lean:79`), two-phase borrows start at `ReservedFrz false`, and `&UnsafeCell<T>` uses `ReservedIM`/`Cell`. Stack unwinding (`Unwind.lean:47-120`) executes drop glue along `cleanup` edges without normal return; unlike Aeneas (which collapses panics to `Result.fail`), explicit `SymState` loan graphs can track cleanup-edge loan release directly once `cleanup` edges are modeled.

## Boundaries

- **Automatic general-reference MIR-to-`PureLift` simulation is `not examined` as a finished upstream theorem**: On `joshlf/anneal@c131b320eeeb26ef692e5afd5ec8db49ee518613`, `MirBridge.liftStraightLineMir` automates straight-line scalar/bool/tuple/enum bodies, whereas general mutable-borrow plans take an explicit `MirRunsTo` proof `hSim` (`MirBridge.lean:58-62`), and `Trusted.MirAst` does not yet expose `MirTy.ref` / `Rvalue.ref`.
- **Direct verification of `core::slice::IterMut::next`'s body in pure Aeneas or unextended Creusot is `unsupported`**: Upstream `IterMut` (`rust-lang/rust@8144389c895da997dbdecaa635e41d6a50be6ffd`, `slice/iter.rs:192-203`) uses raw pointers, ZST provenance punning, and `transmute`; Creusot marks `View` and `resolve_coherence` `#[trusted]` (`slice.rs:739, 753`), and Aeneas rejects nested-mutable-borrow ADTs (`SymbolicToPureTypes.ml:295-300`) and `unsafe` code (`README.md:137-139`).
- **Sub-block spatial splitting in `PureLift.SpatialPin` is currently `unsupported`**: `SpatialPin.lean:168, 276` requires `blk.activeSubSplits == 0` with no `splitSpatialBlock` primitive yet implemented.
