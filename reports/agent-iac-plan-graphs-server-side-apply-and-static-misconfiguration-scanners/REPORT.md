## Summary

Line-level code forensics across eight pinned upstream repositories (`opentofu/opentofu@0183949c`, `hashicorp/terraform@80e6fc28`, `kubernetes/kubernetes@43cbb94e`, `kubernetes-sigs/structured-merge-diff@560aaa51`, `kubernetes/enhancements@cac930cb`, `bridgecrewio/checkov@28694608`, `aquasecurity/trivy@edf9f5c1`, and `autoiac-project/iac-eval@b75a90b3`), fourteen primary specifications and publications, and a deterministic five-suite Python 3.10+ standard-library verification probe (`scripts/verify_iac_terraform_k8s_checkov.py`) establish that **syntactic validity (`validate`) and dry-run planning (`plan`) are neither sufficient for provisioning liveness (`apply`) nor sound proxies for security compliance**:

1. **Plan-to-Apply DAG Divergence, Silent `create_before_destroy` Contagion, and Operational Instability (`Basis: source + execution + documentation`):**
   - **Live `OpenTofu` vs. `Terraform` Apply-Graph Cycle Divergence (`opentofu/opentofu@0183949c` `internal/tofu/transform_destroy_cbd.go:119–149` vs. `hashicorp/terraform@80e6fc28` `internal/terraform/transform_destroy_cbd.go:91–258`):** During Apply-graph construction (*after* `plan` succeeds), `OpenTofu`'s `CBDEdgeTransformer` unconditionally reverses every incoming `GraphNodeCreator -> GraphNodeDestroyer` edge onto a `create_before_destroy` (`CBD`) destroyer. On the 4-vertex regression witness `TestCBDEdgeTransformer_creatorWaitsForDifferentCBDDestroy` (`transform_destroy_cbd_test.go:373–413`), `OpenTofu` forms the Tarjan 3-cycle **`('aDestroy', 'cCreate', 'cDestroy')`**, whereas `Terraform`'s two-phase `!ancestors.Contains(e.Target)` guard (`L195–213`) skips reversing `('cCreate', 'aDestroy')` while reversing `bDestroy -> cCreate`, executing cleanly in order **`['aDestroy', 'cDestroy', 'cCreate', 'bDestroy']`** (`0` cycles).
   - **Upstream `CBD` Contagion & Dual-State Singleton Stranding (`transform_destroy_cbd.go:41–97`, `internal/tofu/node_resource_apply_instance.go:315–324`):** Setting `create_before_destroy = true` on a leaf resource (`R3_attach`) silently forces `CBD` onto all upstream dependencies (`['R1_bucket', 'R2_policy']`; note also `L79–81` where `s == nil` returns `true`). Conversely, `DeleteThenCreate` avoids `duplicate(R1)` while incurring transient `dangling(R2, R1)=True` outages.
   - **Deferred `cty.UnknownVal` Checks, `RefreshOnly` Skew, & Controller State Lag (`node_resource_plan_instance.go:434–532`, `eval_conditions.go:36–69, 116–154`, `Drosos et al. 2024`, `Sieve`, `Anvil`):** Resource preconditions/postconditions referencing unknown computed values (`!resultVal.IsKnown()`, `eval_conditions.go:135–154`) defer silently at `plan` (`plan=DEFERRED_UNKNOWN`) and abort mid-`apply` (`apply=ERROR_CHECK_FAILED`) after mutating upstream resources (`orphaned_upstream=['aws_vpc.main']`).
