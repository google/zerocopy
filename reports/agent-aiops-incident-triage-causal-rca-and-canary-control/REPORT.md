## Summary

Primary-source analysis of eight peer-reviewed papers and preprints (2022–2025), Google Site Reliability Workbook Chapter 5 (2018), line-level code forensics across 30 source files in six pinned public GitHub repositories (`spinnaker/kayenta`, `argoproj/argo-rollouts`, `microsoft/AIOpsLab`, `microsoft/OpenRCA`, `phamquiluan/RCAEval`, `phamquiluan/BARO`), and a deterministic five-pillar Python 3.10+ standard-library verification suite (`scripts/verify_aiops_rca_canary.py`) establishes five core operational laws for autonomous incident triage, root-cause localization, and progressive delivery:

1. **Statistical Localization Dominates Metric/Resource Faults by Five Orders of Magnitude in Speed, While LLM Agents Dominate Semantic Misconfigurations Yet Collapse Under Raw Multi-Modal Context (`BARO`, `CIRCA`, `RCAEval`, `AIOpsLab`, `ITBench`, `OpenRCA`, `RCACopilot`, `RCAgent`):** Robust statistical change-point + scale ranking (`BARO`, `0.01 s`) achieves `0.80–0.81` Avg@5 on 64-service Train Ticket (`RE2`) vs. `7,564.88 s` and `85/100` PC-discovery failures for observational `CIRCA`—whereas `CIRCA` given an authoritative structural graph (`KDD '22`, $D_O$) beats `NSigma` (`+8.1 pp` AC@1) in `0.58 s`. Conversely, on semantic Kubernetes misconfigurations (`AIOpsLab`), `GPT-4` agents reach `61.54%` Acc@1 vs. `15.38%` for statistical `PDiagnose`, yet open-ended multi-modal frontier agents solve only `11.34%` of `OpenRCA` (`0.00%` on 3-element Hard cases) and `13.81%` Diagnosis / `11.43%` Mitigation on `ITBench` (`18.10% -> 9.52%` Diagnosis and `20.00% -> 2.86%` Mitigation—a `7.0×` drop—when traces are disabled, Appendix C Tables 20–21). Raw multi-source context concatenation drops `RCACopilot` Micro-F1 by `-32.6 pp` (`0.766 -> 0.440`), and raw SQL/SLS tools drop `RCAgent` trajectory pass rate by `-33.54 pp` (`99.38% -> 65.84%`, `70.94%` invalid rate).
2. **Canary Judges Fail Both Statistically (AR(1) FWER Explosion + Sample-Size Floor) and Structurally (Fail-Open Edge Defects) (`spinnaker/kayenta@5310ab7d`, `Probe 1`):** Kayenta's Hodges–Lehmann `tolerance = 0.25` raises its i.i.d. two-sided $|Z|$ critical threshold to `3.1018` ($\alpha_{\text{eff, iid}} = 0.0019235$, holding $M = 50$ i.i.d. FWER to `9.18%` vs. naive `63.58%`). However, under Gaussian AR(1) serial correlation ($\rho = 0.8$), Gastwirth–Rubin rank-variance inflation ($V_{\text{MW}, 40}(0.8) = 7.77$) pushes Monte Carlo single-metric FPR to `28.29% ± 2.41%` (analytical `26.58%`) and `M = 50` FWER to `100.0%`—where Holm–Bonferroni and Benjamini–Hochberg alone *still* suffer `100.0%` FWER. Pairing rank-VIF with Holm–Bonferroni imposes a hard minimum sample floor (`n >= 69` merely for complete separation to cross $\alpha/M = 0.0004$; `n = 40` is mathematically vacuous with `0.000` power); at feasible `n = 150`, oracle `VIF+Holm` restores null FWER to `0.013` with `1.000` power on a `+3.0 SD` outage, while plug-in $\hat{\rho}$ exhibits finite-sample Marriott–Pope downward bias (`mean rho_hat = 0.778`, FWER `0.050`). Four concrete judge defects also exist: `n = 1` IEEE-754 exact ties throw `Error (critical = false)` and score `100.00` (while 5-bit exponent-gap pairs like `[1.0]` vs. `[50.0]` stochastically emit zero-width CIs and `High (Critical)` on `191/200` seeds at exact $p = 1.0$), `meanRatio = NaN` bypasses effect-size guards on zero-mean baselines, explicit `nanStrategy = "replace"` silently passes empty series (overriding `critical` and `mustHaveData`, whereas default `"none"` safely maps to `Remove`), and all-`Nodata` groups receive `100.0` when global `Nodata < 50%`.

4. **Progressive-Delivery Controllers Exhibit Cumulative vs. Resetting Counter Asymmetry, Indefinite `Inconclusive` Bleed-Out, and `RunSummary` Miscounting (`argoproj/argo-rollouts@8c9c5ad2`, `Probe 3`):** Default cumulative `failureLimit = 0` yields `70.24%` false-abort probability across `N = 60` polls at $\alpha = 0.02$, whereas resetting `consecutiveErrorLimit = 4` without incrementing `Count` lets an 80%-error provider (`4 Error + 1 Success`) finish `count = 50` after `250` polls (`200` errors) as `Successful`. ### 6. Operational Design Rules for Autonomous Ops & Canary Control

`Basis: derived (synthesized from Sections 1–5)`

1. **Use Hybrid Two-Stage Localization:** Run fast statistical localization (two-sided `max|z|`, unit-normalized zero-IQR scale floor, max/min-pooled resampling, rate-derived counters; `~0.01 s`)—or `CIRCA`-style `RHT` strictly on an authoritative dependency/trace graph—before passing a **summarized top-$k$ bundle** to an LLM triage agent. Never feed raw unsummarized multi-modal dumps (`-32.6 pp` Micro-F1) or run $O(d^3)$ observational PC discovery online over `> 100` metrics.
2. **Encapsulate Diagnostic Tools & Gate Cluster Mutations:** Expose typed read-only helpers and sandboxed Python execution (`OpenRCA` `SandboxedKernel`, `RCAgent` experts) rather than raw SQL/SLS (`-33.54 pp` pass rate) or `shell=True`. Gate every mutating command (`delete`, `scale`, `patch`, `helm uninstall`) behind an explicit allowlist and blast-radius check.
3. **Correct Canary Judges for Autocorrelation + Multiplicity and Enforce Fail-Closed Nulls:** Enforce sample-horizon feasibility (`n >= 69` minimum floor, `n >= 150` operational target at $\rho = 0.8, M = 50, \alpha = 0.02$), account for finite-sample $\hat{\rho}$ downward bias (e.g., bias-adjusted lag estimation or conservative block bootstrap) before Holm–Bonferroni FWER control, ban asymptotic tests below $n \ge 10$, propagate `critical = true` onto `Error`/empty-series paths, never award `100.0` to all-`Nodata`/all-`Error` groups, and replace `meanRatio` on zero-mean baselines with absolute/CLES guards.
4. **Pair Multi-Window Burn-Rate Guards with a Low-Traffic Floor:** Use paired $W_S = W_L / 12$ rules (`1h/5m @ 14.4x`, `6h/30m @ 6x`, `3d/6h @ 1x`) gated by a minimum request-volume or minimum-error-count floor (`>= 70 req/hr` or `>= 5` errors at 99.9% SLO, accounting for thinned-Poisson denominator variance) or synthetic probing.
5. **Fail Closed on `Inconclusive` and Bound Cumulative Provider Errors:** Auto-abort (or enforce a short bounded pause TTL $\to$ auto-abort) rather than parking degraded canary traffic indefinitely; cap cumulative provider `Error` totals alongside `ConsecutiveError`; calibrate `failureLimit` to total poll horizon $N$; and enforce re-rollout backoff hysteresis against autonomous retry loops.
6. **Verify Mitigations End-to-End & Parse Structured Outputs with `JSONDecoder`:** Mitigation checks must assert expected ready-replica cardinality (`>= desired > 0`), `Running` phase with non-empty ready `container_statuses`, and application-level SLI probes (`HTTP 5xx < threshold`). Evaluators must parse JSON with key-order-independent `json.JSONDecoder` and timezone-aware ISO-8601 normalization.
