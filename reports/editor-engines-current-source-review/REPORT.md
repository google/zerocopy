## Claim-mapped source findings

**R383 clangd.** The original evidence map has exact C01–C05 current-source claims about `runWithAST`/invalidation, preamble reads, compile commands, diagnostics, and layered index freshness. We checked the five corresponding commit-pinned LLVM files: `TUScheduler.h`, `ClangdServer.cpp`, `GlobalCompilationDatabase.h`, `index/FileIndex.cpp`, and `index/Background.cpp`. Each old/new Git blob SHA-1 is identical; per-file source SHA-256 values are recorded in the [official observation](support/official-source-observation.json). Independent [LLVM Gitiles history](https://llvm.googlesource.com/llvm-project/+log/ded546ad82656ce6605ee2f2aa60c78dec70d95f..229b9b2f4e20840a8280174fa08385fd9e36844b) establishes the 181-commit forward range. Recursive Git tree comparison inside `clang-tools-extra/clangd` found three changed leaves: `refactor/tweaks/ExtractFunction.cpp`, `unittests/FindTargetTests.cpp`, and `unittests/tweaks/ExtractFunctionTests.cpp`; none is a mapped C01–C05 file. The GitHub compare API returned its 300-file cap for the **whole LLVM repository**, so no whole-repository changed-path completeness or behavior equivalence is claimed. Historical C06–C10 and derived D01–D02 retain their original roles.

**R404 gopls.** The original `G-CURRENT` evidence entry maps the Folder/View/Snapshot/cache and workspace claims to seven `gopls/internal/cache` and documentation files. Each commit-pinned old/new Git blob is identical, matching the frozen old blob IDs. The result concerns selected cache/design files only; it does not revalidate complete gopls behavior or the historical v0.11/v0.12/v0.15 sequence.

## Boundaries and revalidation

No clangd, gopls, rust-analyzer, compiler, language-server host, or Anneal product was installed or executed. Every row records `runtime_result: unexecuted_in_this_review` and `anneal_product_result: unassessed`. The [offline checker](support/check_matrix.py) verifies exact frozen excerpts, metadata and sidecar bytes, corpus reconciliation, recorded ref and ancestry observations, mapped blob identities, and bounded changed paths. It cannot refresh upstream refs or prove the claims' runtime behavior.
