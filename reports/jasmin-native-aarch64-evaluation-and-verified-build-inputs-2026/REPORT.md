# Jasmin native AArch64 evaluation and verified inputs before offline builds

## Summary

The pinned Jasmin Nix environment **evaluates on native AArch64 Linux**, and its proposed cached inputs have been acquired and checked: 191 signed paths passed full offline NAR-content/signature verification. The one uncached coqword source was obtained through Nix's data-only unpack helper and independently rehashed to the exact expected normalized source identity. A separate parent-owned offline Bash-printf derivation also succeeded under the existing sandbox/capability settings. Eighteen dependency derivations remain unbuilt, covering 19 output paths. No compiler, Coq, EasyCrypt, SMT solver or target-code program was executed.

This establishes a concrete input-readiness boundary, not a successful dependency build or theorem replay. The intended Jasmin compiler output remains explicitly **x86-64 with Linux calling convention**; native AArch64 identifies the host tools and dependency environment, not a substituted target ISA.

Source/derivation hashes, cache signatures and a successful input gate establish no compiler theorem.
