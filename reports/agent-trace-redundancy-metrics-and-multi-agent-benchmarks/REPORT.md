# Measuring Duplicate Execution, Duplicate Discovery, and Missed Generalization in Multi-Agent Traces, and Auditing Concurrent Shared-Repository Agent Benchmarks

## Summary

Primary-source audits of 11 pinned public benchmark repositories (`MultiagentBench/MARBLE`, `TheAgentCompany/TheAgentCompany`, `xhguo7/SyncMind`, `openai/preparedness` / `openai/SWELancer-Benchmark`, `commit-0/commit0`, `cooperbench/CooperBench`, `hkust-nlp/AgentBoard`, `patronus-ai/trail-benchmark`, `SalesforceAIResearch/MCPEval`, `Accenture/mcp-bench`, and `YusaeMeow/Collab-Overcooked`), 19 peer-reviewed papers and preprints (2005–2026), and a deterministic five-probe Python verification suite establish three core invariants for measuring redundant agent work and evaluating multi-agent coding benchmarks:

1. **Causal-Epoch Three-Regime Redundancy Decomposition ($W_{\text{exec}}, W_{\text{disc}}, W_{\text{gen}}$) and Compressor Window Bounds (`Probe 1`):** Bag-of-calls and embedding-similarity trace deduplicators misclassify legitimate post-mutation verification (`read_file(f)` or `pytest` after `edit_file(f)` advances world state) as duplicate work (`60.0%` false-discovery rate in `Probe 1`) while missing cross-tool lexical variants (`rg` vs. `grep` at unchanged state) and uninspected clobbered writes. Indexing actions by the SHA-256 Merkle content-epoch $\varepsilon(r_t, t-1)$ of their transitive dependency cone $\text{Cone}(r_t)$ separates productive base work $C_{\text{prod}}$, post-mutation verification $V_{\text{verif}}$, and authorized tail-latency hedging $H_{\text{hedge}}$ from **Type I Duplicate Action Execution** ($W_{\text{exec}} = W_{\text{exec}}^{\text{comp}} + W_{\text{exec}}^{\text{mut}}$: same-epoch deterministic compute re-runs plus backward-sliced dead/reverted mutations), **Type II Duplicate Information Discovery** ($W_{\text{disc}} = W_{\text{disc}}^{\text{intra}} + W_{\text{disc}}^{\text{inter}}$: zero-marginal-gain re-queries intra-agent or across agents), and **Type III Missed Cross-Task Generalization** ($W_{\text{gen}} = W_{\text{gen}}^{\text{bespoke}} + W_{\text{gen}}^{\text{omit}}$: AST-isomorphic bespoke clone patches across modules plus unfixed sibling loci in shared invariant classes; `Park et al., MSR 2012` show `22%–33%` of resolved Eclipse/Mozilla bugs required $>1$ fix attempt and `68.54%–78.75%` of supplementary patches were non-clone contract/call dependencies). For reference-based conformance (`Adriansyah et al., IEEE EDOC 2011`), alignment cost must be minimized across topological linearizations $\sigma \in \mathcal{L}(M)$ of the workflow partial order (`1.0000` vs. `0.8000` single-path penalty on parallel swaps). ## Findings

### 1. Formalizing the Three Redundancy Regimes Over Causal World-State Epochs

`Basis: normative + source + derived + execution + documentation`

#### 1.1 Causal Dependency-Cone Content Epochs Eliminate False-Positive Deduplication

Let a multi-agent execution trace be $\mathcal{T} = (e_1, \dots, e_T)$ generated by agents $a_t \in \{1, \dots, K\}$ over a repository resource universe $\mathcal{R}$ (files, symbol/query cones, build/test targets, service endpoints). Each event $e_t = (t, a_t, \text{op}_t, r_t, \text{args}_t, o_t, c_t)$ incurs resource cost $c_t > 0$ (tokens, API dollars, or CPU-seconds). For any target $r \in \mathcal{R}$, let $\text{Cone}(r) \subseteq \mathcal{R}$ denote its reflexive-transitive causal input cone (for a file $f$, $\{f\}$; for a symbol search `sym:s`, the scoped file set scanned by `s`; for a test target $u$, all source, fixture, and configuration files exercised by $u$). Define the **causal dependency-cone epoch** prior to step $t$ via content-addressed blob hashes $\nu_{t-1}(q) = \text{SHA-256}(\text{blob}_{t-1}(q))$:

$$\varepsilon(r, t-1) = \text{SHA-256}\!\left(\big\Vert_{q \in \text{sorted}(\text{Cone}(r))} \big(q \mathbin{\Vert} \nu_{t-1}(q)\big)\right)$$

Using content hashes $\nu_{t-1}(q)$ rather than an integer edit counter ensures **state equivalence under reverts**: if an agent edits file $q$ from $v_0 \to v_1$ and subsequently reverts $q$ back to exact $v_0$ bytes, $\nu(q)$ returns to $\nu_0(q)$ and $\varepsilon(r, t-1)$ restores $\varepsilon_0$ (`Probe 1` soundness check C). Conversely, evaluating redundancy without conditioning on $\varepsilon(r, t-1)$ fails in both directions (`Probe 1`):
- **Epoch-blind false positives (`3/5 = 60.0%` false-discovery rate in `Probe 1`):** Across an `edit -> verify -> refine` loop (`read(f)` at $v_0 \to$ `edit(f)` $\to$ `read(f)` at $v_2 \to$ `pytest(u)` at $v_2 \to$ `edit(f)` $\to$ `read(f)` at $v_3 \to$ `pytest(u)` at $v_3$), raw `(tool_name, args)` and embedding-similarity deduplicators flag the post-mutation `read(f)` and `pytest(u)` calls (`Steps 7, 10, 11`) as duplicates even though $\varepsilon(r, t-1)$ changed and observing post-edit behavior is causally required. Populating search cones (`dep_cones["sym:parse_cred"] = {"src/auth.py", "src/session.py", "src/api_key.py"}`) likewise ensures post-edit verification searches (`Probe 1` soundness check A) classify as $V_{\text{verif}}$ rather than $W_{\text{disc}}^{\text{intra}}$.
- **Lexical and clobbered-write false negatives (`2` missed waste steps in `Probe 1`):** When Agent $A$ runs `grep -rn parse_cred src/` at $\varepsilon_0$ (`Step 2`) and Agent $B$ runs `rg parse_cred src/` at the identical $\varepsilon_0$ (`Step 3`), raw tool/argument matching misses the duplicate discovery (`sym:parse_cred` at $\varepsilon_0$), and also misses Agent $B$'s uninspected clobbered `edit_file` (`Step 5`) because its argument payload is unique.

#### 1.2 Six-Way Cost Decomposition, Resource-Scoped Backward Slicing, and Empirical $W_{\text{gen}}$ Bounds

Total trace expenditure $C(\mathcal{T}) = \sum_{t=1}^T c_t$ plus latent sibling-omission rework decomposes into:

$$C_{\text{effective}}(\mathcal{T}) = C_{\text{prod}} + V_{\text{verif}} + H_{\text{hedge}} + \underbrace{\left(W_{\text{exec}}^{\text{comp}} + W_{\text{exec}}^{\text{mut}}\right)}_{W_{\text{exec}}} + \underbrace{\left(W_{\text{disc}}^{\text{intra}} + W_{\text{disc}}^{\text{inter}}\right)}_{W_{\text{disc}}} + \underbrace{\left(W_{\text{gen}}^{\text{bespoke}} + W_{\text{gen}}^{\text{omit}}\right)}_{W_{\text{gen}}}$$

| Regime | Sub-Term | Formal Predicate over Trace $\mathcal{T}$ | Primary Literature & Operational Mechanism |
| :--- | :--- | :--- | :--- |
| **Type I: Duplicate Execution ($W_{\text{exec}}$)** | $W_{\text{exec}}^{\text{comp}}$ (Idempotent Compute) | $e_t \in \mathcal{A}_{\text{comp}}$ (hermetic build/test) $\land \exists i < t: (\text{target}(e_i), \varepsilon(r_t, i-1)) = (\text{target}(e_t), \varepsilon(r_t, t-1)) \land e_t \notin \mathcal{H}_{\text{authorized}}$ | Re-running deterministic builds/tests at an unchanged dependency-cone hash across agents or turns without tail-hedge authorization (`Step 12`: `600` tokens in `Probe 1`, vs. authorized `Step 13` `hedge_test` credited to $H_{\text{hedge}} = 600$). |
| **Type I: Duplicate Execution ($W_{\text{exec}}$)** | $W_{\text{exec}}^{\text{mut}}$ (Dead / Reverted Mutation) | $e_t \in \mathcal{A}_{\text{mut}}$ with zero surviving state delta in $\sigma_T$ ($\nu_T(q) = \nu_0(q)$ or overwritten) and zero causal diagnostic path to a surviving write | Backward causal slicing (`Step 5`: `900` tokens; `edit -> revert-to-v0`: `1,000` tokens in `Probe 1`); e.g., `Commit0` Stage 2/3 overwriting working Stage 1 code (`cookiecutter`: `108 -> 102 -> 16` passing tests, `Table 2`). |
| **Type II: Duplicate Discovery ($W_{\text{disc}}$)** | $W_{\text{disc}}^{\text{intra}}$ (Intra-Agent Rediscovery) | $e_t \in \mathcal{A}_{\text{obs}} \land \exists i < t: a_i = a_t \land (\text{canon}(e_i), \varepsilon(r_t, i-1)) = (\text{canon}(e_t), \varepsilon(r_t, t-1))$ | Context-window eviction or poor retrieval (`Step 4`: `400` tokens; `TRAIL` `arXiv:2505.08638v3` §2.1: `841` errors across `148` traces, `o3` localization $r = -0.379, \rho = -0.508$ vs. trace length). |
| **Type II: Duplicate Discovery ($W_{\text{disc}}$)** | $W_{\text{disc}}^{\text{inter}}$ (Cross-Agent Rediscovery) | $e_t \in \mathcal{A}_{\text{obs}} \land (\text{canon}(e_t), \varepsilon(r_t, t-1))$ already observed by $a_i \neq a_t$ ($i < t$), not by $a_t$ | Missing or unqueried shared findings (`Step 3`: `300` tokens; `SyncMind` `arXiv:2502.06994v2`: peer query rate $\text{ASR} \le 4.86\%$ despite `+52.63 pp` Oracle ceiling gap). |
| **Type III: Missed Generalization ($W_{\text{gen}}$)** | $W_{\text{gen}}^{\text{bespoke}}$ (Bespoke Clone Proliferation) | Surviving patches $\{\delta_1, \dots, \delta_m\}$ ($m \ge 2$) across distinct files share a non-trivial callee-preserving AST anti-unifier $\alpha = \text{lgg}(\delta_1, \dots, \delta_m)$ | Excess synthesis and maintenance cost $\sum_{j=2}^m \max(0, c(\delta_j) - c_{\text{call}})$ when concurrent agents patch isomorphic logic without factoring a shared helper (`Step 14`: `850` tokens in `Probe 1`). |
| **Type III: Missed Generalization ($W_{\text{gen}}$)** | $W_{\text{gen}}^{\text{omit}}$ (Unfixed Sibling Omission Debt) | Patch fixes $0 < m < K_{\text{sib}}$ loci in an invariant equivalence class $\mathcal{U}$, leaving $K_{\text{sib}} - m$ unfixed siblings (`2,000` tokens in `Probe 1`) | `Park, Kim, Ray, & Bae (MSR 2012)` (`doi:10.1109/MSR.2012.6224298`); `Yin et al. (ESEC/FSE 2011)` (`doi:10.1145/2025113.2025121`: `14.8%–24.4%` of OS fixes—`39%` on concurrency bugs—were incorrect or incomplete). |

- **Soundness Requirements for Backward Causal Slicing and AST Anti-Unification (`Probe 1`, `[controlled trace-decomposition experiment]`):**
  1. *Resource-scoped causal taint vs. monotone whole-agent taint:* `compute_live_edit_slice()` records diagnostic observations per `(agent, resource)` (`agent_res_deps[(a, q)]` for $q \in \text{Cone}(r_t)$) rather than tainting an entire agent globally, and excludes scheduler-dispatched `hedge_test` clones. When Agent $B$ writes a dead edit to `src/auth.py` (`Step 1`), Agent $A$ reads `src/auth.py` (`Step 2`), runs `hedge_test` (`Step 3`), and edits unrelated `docs/README.md` (`Step 4`) before Agent $C$ overwrites `src/auth.py` (`Step 5`), `Step 1` remains dead (`live_edit_steps = [4, 5]`, `W_exec_mut = 900`; `Probe 1` soundness check B), whereas Agent $A$'s diagnosed draft `Step 6` on `src/auth.py` stays live (`[6, 9, 14]`).
  2. *Callee-preserving positional AST normalization:* Alpha-normalizing bound parameters/locals (`v0, v1, ...`) while **preserving external callee identifiers** (`ast_skeleton()` in `Probe 1`) matches isomorphic validation clones (`validate_header(hdr)` == `check_token(tok)`) without collapsing distinct callees (`foo(x) != bar(y)`) or non-commutative argument swaps (`x - y != y - x`).
  3. *File-granular surrogate vs. production hunk/call-graph slicing:* Because `Probe 1` models whole-file overwrites without intra-file diff hunks or cross-file dead-code elimination, production repository analyzers must refine $W_{\text{exec}}^{\text{mut}}$ with **line-hunk-level `git blame` ancestry** (so later disjoint-line edits to the same file do not mark earlier surviving hunks dead) and **entrypoint/test call-graph reachability** (so newly created helper files later abandoned by their caller are pruned rather than treated as surviving).
- **Empirical Non-Clone Ceiling on $W_{\text{gen}}^{\text{omit}}$ (`Park, Kim, Ray, & Bae, MSR 2012`, DOI `10.1109/MSR.2012.6224298`):** Across Eclipse JDT core, Eclipse SWT, and Mozilla, **`22%–33%` of resolved bugs required more than one fix attempt**, and supplementary patches partition into three mutually exclusive slices summing to `100.00%`:
  1. **Branch backports** (`17.88%` JDT, `6.12%` SWT, `12.34%` Mozilla);
  2. **Non-backport clone-similar supplementary patches** sharing $\ge 5$ cloned lines with the initial patch (`11.92%` JDT, `25.34%` SWT, `8.91%` Mozilla); and
  3. **Content-dissimilar supplementary patches** (`70.20%` JDT, `68.54%` SWT, `78.75%` Mozilla; `17.88 + 11.92 + 70.20 = 100.00%` JDT, `6.12 + 25.34 + 68.54 = 100.00%` SWT, `12.34 + 8.91 + 78.75 = 100.00%` Mozilla), driven by missed caller/callee contracts, shared state invariants, and incomplete switch/dispatch updates. Syntactic clone detectors therefore capture $W_{\text{gen}}^{\text{bespoke}}$ and `~9%–25%` of supplementary omissions, but miss **`68.54%–78.75%`** of $W_{\text{gen}}^{\text{omit}}$ without static call/data-flow slicing or cross-module regression suites.

#### 1.3 Partial-Order Conformance Alignment vs. Window-Guarded Compression Overlap (`Probe 1`)

1. **Alignment Conformance Over Partial-Order Linearizations (`Adriansyah, van Dongen, & van der Aalst, IEEE EDOC 2011`, pp. 55–64, DOI `10.1109/EDOC.2011.12`):** Given a normative workflow Petri net or partial-order DAG $M$ with valid firing sequences $\mathcal{L}(M)$ and shortest valid length $|M_{\min}|$, optimal unit-cost alignment minimizes synchronous deviation cost across $\sigma \in \mathcal{L}(M)$:
   $$f_{\text{align}}(L, M) = 1 - \frac{\min_{\sigma \in \mathcal{L}(M)} \kappa(L, \sigma)}{|L| + |M_{\min}|}, \qquad \kappa(L, \sigma) = \kappa_{\text{log}}(L, \sigma) + \kappa_{\text{model}}(L, \sigma)$$
   where $\kappa_{\text{log}}$ counts redundant log insertions ($W_{\text{exec}} + W_{\text{disc}}$) and $\kappa_{\text{model}}$ counts skipped model steps. Minimizing over $\mathcal{L}(M)$ is essential: on a DAG with two concurrent prerequisites (`read:v0 || search:v0 -> edit:v1 -> read:v1 -> test:v1`), aligning `["search:v0", "read:v0", "edit:v1", "read:v1", "test:v1"]` against a single fixed list scores **`0.8000`** (`cost = 2`), whereas minimizing over $\mathcal{L}(M)$ (`dag_alignment_fitness` in `Probe 1`) scores **`1.0000`** (`cost = 0`) on all valid parallel orders while penalizing `4`-step churn (`fitness = 10/14 = 0.7143`, `log_moves = 4`). Because $|\mathcal{L}(M)|$ grows as $O(d!)$ in concurrent branch width $d$, large DAGs require `Adriansyah et al.`'s synchronous-product Petri-net $A^*$ solver rather than explicit linearization enumeration.
2. **Epoch-Qualified `NCD` and the `32 KiB` `DEFLATE` Window Horizon (`Cilibrasi & Vitányi, IEEE Trans. Inf. Theory 2005`, `51(4):1523–1545`, DOI `10.1109/TIT.2005.844059`; `Cebrián, Alfonseca, & Ortega, Commun. Inf. Syst. 2005`, `5(4):367–384`, DOI `10.4310/CIS.2005.v5.n4.a1`):** For serialized epoch-tagged traces $\tilde{x}_a, \tilde{x}_b$ under compressor length $C(\cdot)$, $\text{NCD}(\tilde{x}_a, \tilde{x}_b) = \frac{C(\tilde{x}_a \cdot \tilde{x}_b) - \min\{C(\tilde{x}_a), C(\tilde{x}_b)\}}{\max\{C(\tilde{x}_a), C(\tilde{x}_b)\}}$.
   - *Epoch qualification (`< 1 KiB` traces, `Probe 1`):* On a 12-step legitimate `read -> edit -> test` loop, epoch-blind `DEFLATE` `NCD` between the first and second halves collapses to **`0.0435`** (falsely signaling stagnation), whereas epoch-qualified `NCD` separates legitimate causal progression (**`0.4583`**) and disjoint exploration (**`0.8571`**) from true cross-agent duplicate work (**`0.0816`**).
   - *`DEFLATE` `32 KiB` window collapse & non-metricity (`Probe 1`):* Raw `DEFLATE` (`zlib`, `wbits=-15`) uses a $2^{15} = 32{,}768$-byte LZ77 sliding window (`Cebrián et al., 2005`). Once $|\tilde{x}_a| > 32\text{ KiB}$ (`> 64 KiB` concatenated), `DEFLATE` cannot match identical blocks across the window boundary, so $C(\tilde{x} \cdot \tilde{x}) \approx 2\,C(\tilde{x})$: on two **byte-identical** `1,200`-event traces (`70,799` UTF-8 bytes each), **`ncd_deflate(x, x) = 1.0106 > 1.0`** (reaching `~1.045` on higher-entropy step labels)! On short traces, `DEFLATE` block-header overhead also violates **identity** (`ncd(["read:a:v0"], ["read:a:v0"]) = 0.2727 != 0`), **symmetry** (`|0.5000 - 0.5625| = 0.0625`), and the **triangle inequality** (`0.2778 > 0.0000 + 0.1667` on pairwise-distinct triples; `0.1333 > 0.0000` when $x = z$). Production `NCD` estimators must enforce **`|\tilde{x}_a| + |\tilde{x}_b| \le 32{,}768` bytes** for `DEFLATE`, switching above `32 KiB` to **`lzma` (`LZMA2`, `8–64 MiB` dictionary: `ncd_lzma2(x, x) = 0.0099` at `70.8 KB`)** or exact/MinHash Jaccard similarity over `(canon(e_t), ε(r_t, t-1))` multisets.

### 3. Methodological Traps When Measuring Fleet Efficiency and Duplicate Work

`Basis: normative + source + derived + execution + documentation`

#### 3.1 Separating Parallel Fan-Out Width, Verification, and Hedging From Sequential Churn (`Probe 5`)

1. **Parallel Call Width ($W_{\text{par}} = \text{Calls} / \text{Rounds}$) on `MCP-Bench` (`arXiv:2508.20453v1`):** Across all `20` evaluated models (`tables/results_overall.tex` & `tables/execution_stats.tex`), `#1`-ranked `gpt-5` (`0.749` score) issues **`78.9` calls/task**—`2.79x` more than `#2` `o3` (`28.3`, `0.715`) and `4.81x` more than `qwen3-235b-a22b-2507` (`16.4`, `0.678`)—but batches them into **`9.2` rounds (`8.58` parallel calls/round vs. `o3`'s `4.49`)** to raise multi-server grounding (`0.828` vs. `0.706`), whereas `#20` `llama-3-1-8b-instruct` (`0.428` score) stretches `155.6` calls across `17.3` sequential rounds. Across all `20` models (`Probe 5`), raw call count correlates weakly with capability (Spearman $\rho = -0.3609$), round count is sharper ($\rho = -0.4321$), and parallelism/redundancy-adjusted efficiency correlates at **$\rho = +0.9470$**.
2. **Verification ($V_{\text{verif}}$) and Tail-Latency Hedging ($H_{\text{hedge}}$) Exemption (`Dean & Barroso, Commun. ACM 2013`, `56(2):74–80`, DOI `10.1145/2408776.2408794`):** Deferring backup requests until the `95th` percentile cuts `1,000`-key BigTable $P_{99.9}$ latency from `1,800 ms` to `74 ms` (`24.3x`) at `+2%` extra requests (`Dean & Barroso, 2013`; likewise, in a `[synthetic 12-worker JSQ-2 queueing simulation at ρ = 0.80]`, rolling-$P_{95}$ Cancel-on-Complete hedging cuts `P99` response time by `-47.8%` at `3.7%` extra starts). Fleet instrumentation must separate epoch-advancing $V_{\text{verif}}$ and scheduler-tagged $H_{\text{hedge}}$ before reporting net waste $\widehat{W}_{\text{net}} = (W_{\text{exec}} + W_{\text{disc}} + W_{\text{gen}}) / C(\mathcal{T})$.

## Boundaries

- **`not examined` — Live Multi-Container End-to-End Benchmark Runs:** Multi-container Docker, Modal, and GCP Batch environments (`MARBLE` Minecraft/Database, `TheAgentCompany`'s 4-service stack, `CooperBench` containers, `SWE-Lancer` Playwright monoliths, `Commit0`, and `SyncMind`) were not executed live against LLM APIs; evaluator properties were established by direct source inspection at pinned 40-char commits and verified via deterministic standalone ports (`Probes 2–4`).
- **`known not to apply` — Unguarded `DEFLATE` `NCD` Beyond `32 KiB`, Single-Path DAG Alignment, Whole-File Slicing on Multi-Hunk Edits, and Raw/Conditional Cost Means:**
  1. `zlib`/`DEFLATE` (`wbits=-15`) `NCD` **does not apply** once concatenated serialized traces exceed `32,768` bytes (`ncd_deflate(x, x) = 1.0106 > 1.0` at `70,799` bytes/trace) and is non-metric on short traces (`Cebrián et al., 2005`).
  2. Single-linearization alignment (`linear_alignment_fitness`) **does not apply** to concurrent DAG branches (`0.8000` false penalty on valid parallel swaps; minimize over $\sigma \in \mathcal{L}(M)$ via $A^*$ alignment).
  3. Whole-file overwrite slicing (`compute_live_edit_slice()` in `Probe 1`) **does not apply** without hunk-level `git blame` when multiple non-overlapping hunks in one file survive independently, and requires entrypoint call-graph reachability to prune abandoned multi-file helper modules.
  4. Epoch-blind call deduplication, unconditional mean steps $\mathbb{E}[S]$, conditional pass cost $\mathbb{E}[C \mid Y=1]$ alone, and `arXiv:2402.13264v1` (which is *KGroot* by `Wang, Qi, & Wu`, **not** `SyncMind` `arXiv:2502.06994v2`) **do not apply**.
- **`unknown` — Pre-Failure Recall of Static $W_{\text{gen}}^{\text{omit}}$ Slicers on Open-Ended Multi-Agent Traces:** Because `68.54%–78.75%` of supplementary patches in `Park et al. (MSR 2012)` are non-clone-similar, the exact recall of static call/type dependency slicers prior to test execution on arbitrary polyglot agent commits remains open.
- **`unsupported` — Native `W_disc` and `W_gen` Grading in Upstream Harnesses:** None of `MARBLE` (`8892e9cfb6`), `TheAgentCompany` (`98b68ef82a`), `SyncMind` (`a48c469fc7`), `SWE-Lancer` (`b78dab1da7`), `Commit0` (`1123db3321`), or `CooperBench` (`63b9d44d9f`) natively penalize cross-agent duplicate discovery ($W_{\text{disc}}^{\text{inter}}$) or missed sibling generalization ($W_{\text{gen}}$).
