### 7. Engineering Design Rules for Benchmarks, Discovery Loops, and Automated Review

`Basis: derived`

1. **Per-Question Isolated, Tolerance-Floored & Oracle-Self-Tested Benchmark Harnesses:** Isolate every benchmark question inside its own `try ... except` block, enforce `not isinstance(v, bool)` before `int`/`float` checks, apply an IEEE-754 floor $\max(\text{interval}, \text{atol} + \text{rtol}|\bar{x}|)$ when ground-truth sample variance $s = 0$, tag modalities via structured schema fields rather than `'fig' in key`, assert `v1.shape == v2.shape` before `np.allclose`, zero-pad HDF5 sequence keys (`f"var{i:06d}"`), and enforce CI tests verifying `score(gold_oracle) == 100.0%` and `score(partial_prefix) < 100.0%` (including nested `dict`-of-`list` structures).
2. **Immutable Sandboxed Data/Metric Provenance in Autonomous Research Loops:** Mount train/validation/test splits and metric-evaluation scripts read-only outside the agent's writable workspace, verify split hash disjointness mechanically, and cross-check generated LaTeX numerical claims against immutable run logs before any LLM review pass.
3. **Injection-Sanitized, Blind-Median & Execution-Anchored Automated Review:** Strip zero-opacity, white-on-white, micro-font (`< 4pt`), and off-page PDF text layers via OCR-vs.-PDF-text diffing, fence manuscript text as untrusted data, blind reviewers from peer ratings during initial rebuttal revision, aggregate ratings via order-statistic medians over global calibrated thresholds rather than small shuffled AC batches (`2.97x` flip reduction), never overwrite a $K$-review ensemble with a single reflection call (`1.50x` MSE penalty at $K=5, w=0.5$), and compute `Decision` deterministically from final aggregated scores.
