# Local capture-to-consumer research

*Authored by an AI agent acting on joshlf's behalf.*

This experiment executes the post-PR96 program against baseline
`89fe80297563782279a6218ce1c433c92ef58262`. It tests one reusable supported
pipeline and one ownership-cost challenge. Production architecture adoption and
foundation integration remain separate decisions.

## Subjects and claims

The native subject is a new macOS ARM compilation using installed rustc
`1.100.0-nightly (923c95cdf5ba65cea505aa2ea829f578e1506ed8)`.
Its initial subset is sequential scalar/branch/local direct-call code, selected
sized nominal struct facts, and explicitly enumerated operations. Its producer
uses typed compiler fields and rejects unsupported selected-closure forms.
The exact supported inventory is in `native/README.md` once integrated.

Retained Linux H3/q3/r10/strongest-Charon captures keep their recorded compiler,
target and acquisition class. Their raw companions are ingested mechanically
into the existing Lean consumers. They supply the existing operational contract,
nominal/layout and UB/cleanup-sensitive evidence. They are not attached to a new
native invocation as if recaptured. Each accepted subject identifies its own
model, observation policy, raw inputs and remaining acquisition assumptions.

The transport parser, compiler exporter and JSON adapters stay outside semantic
authority. A parser/admission theorem states the checked representation facts;
it does not prove faithful Rust capture, compiler correctness or adequacy of the
research operational model. Missing foundation execution interfaces are named
dependencies rather than invented APIs. No protected core file is modified.

## Execution and acceptance

1. Freeze actual source/context/entrypoints and structural support; no hidden
   specimen-name dispatch may supply operational meanings.
2. Compile the smallest native capture pilot, then capture its typed graph and
   queried facts. Native compatibility evidence is a new host/compiler result.
3. Consume actual bytes and raw companion tables. No manually transcribed
   nominal/layout records receive ingestion credit. Public admission exposes
   identity, phase, closure, layout and representation obligations together.
4. Mutate raw inputs through that same consumer: malformed/truncated/unknown
   schema, duplicate identities, exchanged nominal/layout/target/dependency
   context, high-bit values and the retained checksum/local-type controls.
5. Exercise offline Cargo cold/warm/changed dependency/configuration/generated
   inputs and completed-generation publication. Safe initial warm behavior is
   refusal of a new request without fresh compatible capture. Explicit old
   subject revalidation remains distinguishable from a new verified request.
6. Package reusable library evidence and distinguish contract-parametric reuse
   from implementation-specific claims. State all supplied library assumptions.
7. Have an independent worker choose one bounded extension/refactoring and
   measure actual edits, interface coupling and validation effort. Compare the
   strongest retained ULLBC adapter fairly; fresh acquisition cost may remain
   unavailable if compatible tooling is absent.
8. Independently challenge the joined path, resolve material findings and
   publish exact evidence, limitations and the resulting route recommendation.

Native normal execution and retained cleanup proofs must never be conflated
into a claim about one fresh Rust program. The final report identifies which
path each theorem or observation concerns. Nontermination/all-prefix transfer is
conditional future work unless a claim in this slice requires it; no finite
terminal check is relabeled as an all-prefix theorem.

## Resources and stops

Compiler/Cargo/Lean jobs are serialized by the parent. Lean uses the inherited
`-j1 -M768 -DElab.async=false`,45-second deadline and1-GiB sampled OS RSS stop.
New native pilot bounds are prospectively60seconds and2GiB sampled RSS; compiler
process and child status remain distinct. Sampling does not establish a hard OS
bound. Raw stdout/stderr/status are retained, and unexpected panics or resource
stops suspend the affected frontier before diagnosis.

No new bespoke native supervisor is introduced. Preserve stopped #27/PR24
source-import work, PR29 invariant128, PR30 atomic-prefix cap, PR44 service
interval, and retired #35 supervisor. Iris/Kraken execution stays deferred.
Two materially different bounded approaches per blocker precede narrowing or a
recorded decision-consequential limitation. No larger cap or renamed retry may
erase a stop or failed result.
