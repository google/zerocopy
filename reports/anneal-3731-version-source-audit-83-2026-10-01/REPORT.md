# Source-version audit of 83 remaining inventory rows

## Summary

This audit accounts for **all 83** rows outside the 361 newer-version rows: **72** `source_revision_recheck` and **11** `prior_comparison` rows in the frozen 581-row version inventory. The [per-ID crosswalk](status-83.csv) reports **21 changed**, **55 unchanged**, and **7 unavailable** source comparisons **at the stated mapped scope**. These labels describe inspected source objects or earlier claim-scoped source reviews. They do not say that runtime behavior changed or stayed the same. All 83 target runtimes remain unexecuted in this audit; Anneal product behavior is unassessed.

The two most important distinctions are visible in every CSV row. `basis=direct_git_object` means this audit compared old and target Git objects for listed files or trees. `basis=inherited_published_review` means a named, hashed source-review package supplied the claim-scoped comparison. `basis=no_claim_mapped_comparison` means the historical claim has no adequate newer source comparison, even though the target release identity is known. Rows with only an ancillary Anneal design or packaging check retain an explicit gap; an unchanged ancillary file does not revalidate another tool's behavior.

## Method and limits

`build_review_map.py` selects all 83 IDs and freezes report/review bytes. `build_local_pairs.py` checks local Google Git files/trees without lazy fetch. `build_bundle_pairs.py` checks named release objects from the locally cached Aeneas, Charon, and Lean source repositories. `probe_default_refs.py` records read-only upstream refs. `build_status.py` produces the CSV and exact inherited-review target details in [review-details-83.json](evidence/review-details-83.json). [check.py](check.py) verifies the 83 exact IDs, 72/11 split, original reports and source-review matrix hashes, all **302** listed Git object pairs, source-relation vocabulary, and the frozen 62/63 default-ref result. It does not authenticate GitHub/Gitiles independently on replay, compile any source, or validate runtime equivalence.

The inherited review packages were authored at their own frozen source refs, often earlier on 2026-09-30. A moving default branch may have advanced before the 2026-10-01 ref observation. This audit therefore gives a complete **inventory and scoped source evidence** rather than pretending every external default branch was re-reviewed at the exact later tip. Historical empirical results remain valid only at their original toolchain pins. A behavior-difference report requires a new execution of its retained fixture under the named newer toolchain; a changed Git blob alone is not such a report.
