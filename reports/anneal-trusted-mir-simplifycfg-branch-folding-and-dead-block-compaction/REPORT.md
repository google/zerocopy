# Direct `Trusted.MirSemantics` Verification of `SimplifyCfg`, `SwitchInt` Branch Folding, Acyclic `Goto` Threading, and the Dead-Block `always_storage_live` Hazard

## Summary

`compiler/rustc_mir_transform/src/simplify.rs` (`SimplifyCfg`) and `simplify_branches.rs` (`SimplifyConstCondition`) run repeatedly across Rust MIR phases (`Built`, `Analysis`, `PostAnalysis`, `PreOptimizations`, and `Final`) to strip `nop` statements, fold constant `SwitchInt` terminators, collapse uniform-target `SwitchInt` terminators, thread empty `Goto` chains, and delete unreachable basic blocks (`remove_dead_blocks`). This package directly imports `Trusted.MirAst` and `Trusted.MirSemantics` from `joshlf/anneal@c131b320eeeb26ef692e5afd5ec8db49ee518613` (`support/AnnealTrustedMirSimplifyCfg.lean`, `8982` lines, `397135` bytes, SHA-256 `eb0247dcc1c3f2816989ff4dafa3f43d775ed6a75deae18514e0e6c75e80dd48`) to prove exact soundness and verification-condition (VC) transport theorems for all five transformations, paired with live execution probes on `rustc 1.102.0-nightly` (`rust-lang/rust@3ef0c22cdb86ac42dc6b8f0f1ec36857daa6f2a1`), `Miri`, and `google/zerocopy@e9bc37a4d2c0ad9be243f25db28ff21624d8102b`. Key findings:

1. **Unconditional bidirectional equivalence (`↔` including infinite `Diverges`) for `StripNops`, validated `ConstBranchFold`, and ranked `AcyclicGotoThread`.** Stripping `StatementKind.nop` (`stripNops_bidirectional_iff`), folding `SwitchInt(.constant c, targets) -> Goto(target)` when `resolveConstSwitchTarget c targets = some target` (`constBranchFold_bidirectional_iff`), and threading predecessor edges along strictly rank-decreasing empty non-cleanup `Goto` blocks (`acyclicGotoThread_bidirectional_iff`) preserve `WellFormed`, `Behavior`, `ReachesResult (.fault k)`, infinite `Diverges`, `SatisfiesPost`, and `BodyVerified` in both directions (`↔`) without `Classical.choice` or `Quot.sound` (relying strictly on `[propext]`). `Basis: execution (Lean kernel)`
2. **Surprising live `rustc` + `Miri` `-Zmir-preserve-ub` bypass in `SimplifyCfg::remove_dead_blocks` (`ce_dead_block_elim_flips_always_storage_live_unsound`).** Because `always_storage_live_locals` (`compiler/rustc_mir_dataflow/src/impls/storage_liveness.rs:15-27`, called at frame entry in `compiler/rustc_const_eval/src/interpret/stack.rs:498-503`) and `Trusted.MirSemantics.hasStorageAnnotation` scan **every** basic block in `body.basicBlocks`—including CFG-unreachable blocks—deleting an unreachable block holding the sole `StorageLive(_k)` or `StorageDead(_k)` marker flips `hasStorageAnnotation` from `true` to `false`, promoting `_k` from entry-`.dead` to entry-`.live` in reachable code. While `Miri` (`src/tools/miri/src/lib.rs:200-204`) passes `-Zmir-preserve-ub` by default and `SimplifyCfg::simplify_branch` (`simplify.rs:131-132, 308-330`) checks `preserve_switch_reads`, `simplify.rs:87` calls `remove_dead_blocks(body)` (`simplify.rs:351-415`) unconditionally without checking `mir_preserve_ub` or `MirPhase::Built | MirPhase::Analysis`. On live `rustc 1.102.0-nightly` + `Miri`, an unreachable `bb_unreachable = { StorageLive(a); Return() }` causes `Miri` to report `Undefined Behavior: accessing a dead local variable` (`rc = 1`) when `SimplifyCfg` is disabled, yet `+SimplifyCfg-final` deletes `bb_unreachable` and causes `Miri` to exit `0` **even when `-Zmir-preserve-ub=yes` is explicitly passed**. `Basis: source + execution + execution (Lean kernel)`
3. **Real-world `hasStorageAnnotation` flips in `google/zerocopy@e9bc37a4d2c0ad9be243f25db28ff21624d8102b`.** Across `zerocopy`'s `4,688` MIR bodies (`4,301` post-inlining), `SimplifyCfg` removes `3,121` dead blocks (`-17.8%`), `3,187` `nop` statements (`100%`), and `624` empty `Goto` blocks at `SimplifyCfg-post-analysis`, `551` dead blocks at `SimplifyCfg-pre-optimizations`, and `196` dead blocks at `SimplifyCfg-final`—where **`7` real `zerocopy` functions (`50` total locals, including `layout::{impl#1}::extend` `74 -> 37` BBs / `12` locals and `util::copy_unchecked` `9 -> 4` BBs / `5` locals)** experience `hasStorageAnnotation` `true -> false` flips when cold unreachable blocks are deleted. `Basis: execution`
4. **Certified reverse VC transport (`checkUniformBranchProgram` & `checkDeadBlockStorageSafeProgram`) and `CrateTheorem` pipeline composition.** Uniform `SwitchInt -> Goto` collapse (`codegen_uniformBranchCollapse_refines_unconditional`) and bijective dead-block compaction (`codegen_deadBlockCompaction_refines_unconditional`) are unconditionally forward-sound for codegen (`pSrc -> pTgt`), and pairing them with `checkUniformBranchProgram` (`vc_transport_uniformBranchCollapse_certified_iff`) and `checkDeadBlockStorageSafeProgram` (`vc_transport_deadBlockCompaction_certified_iff`) restores full bidirectional equivalence (`↔`) and end-to-end 5-stage `CrateTheorem` / `UnitTheorem` transport (`simplifyCfg_pipeline_crate_and_unit_iff`). ## Findings

### 1. Upstream `SimplifyCfg` Architecture & the `-Zmir-preserve-ub` Asymmetry

`Basis: source + execution`

In `compiler/rustc_mir_transform/src/simplify.rs` (`rust-lang/rust@8144389c895da997dbdecaa635e41d6a50be6ffd` and `3ef0c22cdb86ac42dc6b8f0f1ec36857daa6f2a1`, L30–35, L81–91, L131–132, L308–336, L351–415), `simplify_cfg` executes two phases:

1. `CfgSimplifier::simplify()` strips `StatementKind::Nop` (`strip_nops`, L332–336), collapses empty `Goto` chains (`collapse_goto_chain`, L229), merges single-predecessor `Goto` successors (`merge_successor`, L281), and collapses uniform-target `SwitchInt` terminators (`simplify_branch`, L308–330).
2. `remove_dead_blocks(body)` (invoked at L87, defined at L351–415) computes CFG reachability from `START_BLOCK` (`bb0`) and drops unreachable basic blocks.

Because `SimplifyCfg` runs on `Built` and `Analysis` MIR as well as under `Miri` (which injects `"-Zmir-preserve-ub"` in `src/tools/miri/src/lib.rs:200-204` at `rust-lang/rust@3ef0c22cdb86ac42dc6b8f0f1ec36857daa6f2a1`), `CfgSimplifier::new` (L131–132) sets:

```rust
let preserve_switch_reads = matches!(body.phase, MirPhase::Built | MirPhase::Analysis(_))
    || tcx.sess.opts.unstable_opts.mir_preserve_ub;
```

However, `remove_dead_blocks(body)` at L87 is invoked **outside** `preserve_switch_reads`. Meanwhile, in `compiler/rustc_mir_dataflow/src/impls/storage_liveness.rs:15-27` (called at frame entry in `compiler/rustc_const_eval/src/interpret/stack.rs:498-503` and mirrored verbatim by `Trusted.MirSemantics.hasStorageAnnotation` and `initLocalsLoop`), `always_storage_live_locals(body)` marks a local `_k` (`k > argument_count`) as dead on entry if and only if **any** basic block in `body.basic_blocks`—reachable or unreachable—contains `StorageLive(_k)` or `StorageDead(_k)`.

Live execution on `rustc 1.102.0-nightly` (`3ef0c22cdb86ac42dc6b8f0f1ec36857daa6f2a1`) + `Miri` (`support/e3_2_simplifycfg_miri_and_zerocopy_summary.json`) confirms this exact discrepancy:

| :--- | :---: | :---: | :---: | :---: | :--- |
| `ce1` (`runtime` dead-block `StorageLive`), `miri -SimplifyCfg` | `2 -> 2` | `true` | `false` | `1` | `Undefined Behavior: accessing a dead local variable` |

| `ce1` (`runtime` dead-block `StorageLive`), `miri -Zmir-preserve-ub=yes +SimplifyCfg-final` | `2 -> 1` | `false` | `false` | **`0`** | **None (UB silently erased)** |

## Boundaries

1. **Unmodeled `SimplifyCfg` & `SimplifyConstCondition` sub-passes (`known not to apply` / `not examined`).** Upstream `SimplifyCfg` also concatenates single-predecessor `Goto` blocks (`merge_successor`, `simplify.rs:281`), strips `SwitchInt` arms equal to `otherwise` (`simplify_duplicate_switch_targets`, `simplify.rs:339-349`), and deduplicates empty non-cleanup `Unreachable` blocks inside `remove_dead_blocks` (`simplify.rs:352-396`); upstream `SimplifyConstCondition` (`simplify_branches.rs:35-96`) also folds `Intrinsic::Assume(const)` (`L59-69`), `TerminatorKind::Assert` (`L86-92`), and adjacent `_x = const c; SwitchInt(copy _x | move _x, targets)` (`pre_place_const`, `L43-48, 70-85`). `VrustcFormal.F1_5` scopes strictly to `StripNops`, `Operand.constant` `ConstBranchFold`, `UniformBranchCollapse`, `.goto`/`.switchInt` `!bb.cleanup` `AcyclicGotoThread`, and bijective `DeadBlockCompaction`. Under $M_{	ext{anneal}}$'s `deinitMovedPlace = true` semantics, upstream's `pre_place_const` folding of `SwitchInt(move _x)` is forward-only unless `_x` is certified unread before overwrite.
2. **Scope of `Trusted.MirSemantics` (`mirProfileVersion = 1`, `unsupported`).** Inherited directly from `joshlf/anneal@c131b320eeeb26ef692e5afd5ec8db49ee518613`: 64-bit targets (`pointerWidthBits = 64`), value-only entry parameters (`callerMem = ⟨[]⟩`), unprojected scalar/`bool`/`()`/`!`/fieldless-enum locals, conservative `Operand.move` deinitialization (`deinitMovedPlace = true`), and fail-closed `.fault .unsupported` on `call`, `assert`, `unwindResume`, projected places, and references.
3. **`BodyAbsCert` (`checkUniformBranchProgram`) soundness vs. completeness (`known not to apply`).** `BodyAbsCert` is a sound, flow-sensitive, path-insensitive 3-point abstract interpreter (`liveInit`, `liveUninit`, `dead`), not a complete characterization of `FullSemanticEquiv` for `UniformBranchCollapse`. Because `checkUniformBranchBody` requires `cert[0] = some env₀` on non-empty bodies and checks `stepAbsStmts` across all syntactically `cert`-reachable blocks (even when zero `SwitchInt`s are collapsed in Theorem 6), it conservatively rejects path-correlated diamond initializations, syntactically reachable dead branches with uninitialized reads prior to branch folding, unmodeled statement/rvalue constructors, and uninhabited-parameter (`MirTy.never`) bodies that `.return_` without initializing `_0`.
4. **`checkDeadBlockStorageSafeProgram` conservatism & surface Rust vs. `#[custom_mir]` (`known not to apply`).** Exact `hasStorageAnnotation` preservation for `idx > argumentCount` is sufficient for reverse VC transport (`Theorem 5b`) and sharp when `_idx` is accessed in surviving blocks without a dominating `StorageLive` (`ce1`), but conservatively rejects deleting dead blocks whose local temporaries never appear in `bTgt` (as in the `7` `zerocopy` functions at `SimplifyCfg-final`, where `FullSemanticEquiv` still holds). Conversely, the live `Miri` `-Zmir-preserve-ub` UB-erasure (`ce1`) requires reachable code to access a storage-annotated local without a dominating `StorageLive`, which arises in `#[custom_mir]` or buggy MIR passes rather than well-scoped surface Rust lowered by `rustc_mir_build`.
5. **Downstream scaling benchmark (`Findings §4`, `not examined` for symbolic WP).** The `K = 4..32` `Lean v4.34.1` benchmark measures concrete-input (`{ args := [u32Val 41] }`) kernel definitional reduction (`by rfl` on `execStepLoop`) over synthetic `4K + 1 -> 2` block pipelines, not universally quantified symbolic `Anneal.MirWp` proofs over real `zerocopy` bodies.
6. **Functional property invariance (`prop p₅ ↔ prop p₀`).** In `simplifyCfg_pipeline_crate_and_unit_iff`, `Specs.property : Program → Prop` (`Trusted/MirSemantics.lean:1768`) is an arbitrary Lean predicate over the `Program` AST record. Semantic properties defined via `WellFormed`/`Behavior`/`Diverges` satisfy `prop p₅ ↔ prop p₀` automatically via `FullSemanticEquiv p₀ p₅`, whereas syntactic AST-counting predicates (such as `p.bodies[0].basicBlocks.length == 6`) intentionally do not.
