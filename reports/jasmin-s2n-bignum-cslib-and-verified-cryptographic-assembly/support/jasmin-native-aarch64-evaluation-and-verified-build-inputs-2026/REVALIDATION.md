# Revalidation without rebuilding the experiment implicitly

The package is self-contained for reading the result and rerunning host-only metadata guards. It deliberately contains no OCI layer, tool binary, NAR or full source mirror. Reproducing runtime operations therefore requires separately authorized reacquisition of the immutable inputs, not private host state.

1. Verify package-manifest.json; verify archive bytes/member hashes against support/archive-members.json.gz. Inspect support/omitted-bulk-artifacts.json so that large readback/image payload omissions are not mistaken for delivered content.
2. Run `python3 -B check_bootstrap.py`. This checks manifest/config byte hashes, the observed runtime image Id role, arm64/Linux identity and complete diff_id order; wrong-manifest/config/architecture controls must reject. It does not rehash excluded layer payloads or prove image build correctness. Then run `python3 -B check_evidence.py` to compare exact preserved statuses/streams, graph, roots, signatures/reference records, full-verification argv and coqword hash/census. This is consistency checking of evidence, not replaying Nix or proving its implementation.
3. Extract the three phase receipt archives into a new owned evidence directory. Compare the granted root-list SHA256 94f52a3b0ad9038c84cac5397d2f1b6455c9234cd88098e9cf7943f76dbe2dff, exact input/output derivation relationships, all native process statuses/streams and typed source/census comparisons. Preserve raw schema 4 derivation JSON including structuredAttrs. Historical native paths/drivers are records, not commands to run against another existing container.
4. With new runtime authority only: reacquire the same platform image and verify its manifest/config/layer identities; preserve the explicit byte-identical group overlay and effective policy. Verify the exact fresh Jasmin tree using the complete source manifest, then evaluate with the preserved root arguments, not moving channels or ecRef=dev. Record any platform/filter/trust difference as a new subject.
5. Cache copy remains a data-only gate: verify all roots/closure metadata and trusted signatures, use `nix copy --from CACHE PATH`, and require that the only valid-path additions are the exact requested roots. Distinguish already present content-addressed evaluator records. Do not replace copy with a build/realize command or disable signature checks. Check real disk/free samples, not just NAR totals.
6. Full local verification is `nix --offline store verify --sigs-needed 1` over the exact 191 roots, **without --no-contents and without repair**. The complete executed argv is in coqword-data-gate/full-content-signature-verify.json. The earlier metadata-only signature command is not an equivalent content check.
7. Coqword acquisition must use the exact pinned archive, `prefetch-file --unpack --name source` with the required expected normalized hash and expected path. Rehash using `nix --offline hash path --type sha256`; never alter normalization to satisfy the pin. Different source/archive URLs or a hash mismatch require diagnosis and new authority.

These steps establish only input identity/availability and local integrity. A separate archived parent-owned phase already detached network and ran only the owned printf derivation; its raw result does not generalize to package builds. Check that Networks={} is distinct from the retained HostConfig bridge mode, and verify the explicit max-jobs=1 override and exact 19-byte output. Real dependency build setup/compilation remains a separately authorized next gate. Coq/compiler/EC builds, recursive kernel/import checks, individual theorem assumptions, source/target configuration instantiation and ABI/Rust correspondence remain future work. Resource ceilings in the historical receipts are observations/operational policy, not a grant or demonstrated sufficient budget for that work.
