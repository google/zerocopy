# MiniRust Byte Representation Transfers, Pointer Provenance Laws, Codec Coherence, and Primitive/Target Lowering Boundaries

## Summary

MiniRust (`minirust/minirust` at commit `d821c6e3a3d358fa8a556774dc12b4aa5d0d65ed`) defines a three-layer representation and memory-access architecture (`spec/lang/representation.md`, `spec/lang/well-formed.md`, `spec/prelude/target.md`): (1) byte-level value encoding and decoding (`Type::encode` and `Type::decode` over `AbstractByte<Provenance>`), (2) runtime value and pointer metadata validation (`Machine::check_value` over `Pointer<Provenance>`, slices, and trait-object vtables), and (3) operational memory permissions (`BasicMemory` vs. `TreeBorrowsMemory`). Because typed value decoding discards padding and scalar provenance while raw byte transfers preserve `AbstractByte` snapshots verbatim, typed copies (`*dst = *src`), raw copies (`ptr::copy`, `ptr::copy_nonoverlapping`), and integer transmutations induce distinct downstream memory states.

This report synthesizes four investigations—22 machine-checked Lean 4 (`4.34.1`) modules (20 modules in `support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/` plus 2 standalone modules in `support/minirust-representation-copy-provenance-laws-d821c6e/`), native `aarch64-apple-darwin`, `x86_64-unknown-linux-gnu`, and `wasm32-unknown-unknown` Rust layout and numeric probes across `rustc 1.99.0`, `1.99.1`, and `1.101.0-nightly`, and four finite-state Python probes—establishing five core reference findings:

1. **Raw Snapshot Copies vs. Policy-Qualified Typed Transfers (`Representation`, `ByteMemory`, `PartialTransfers`, `Transfers`, `PrefixTransfer`):** Snapshot-based raw byte copying (`ptr::copy` / `ptr::copy_nonoverlapping`) preserves initialized padding, uninitialized cells, and partial pointer fragments (including out-of-order two-piece pointer assembly: `partial_copies_assemble_pointer`), and retains post-read permission states if a subsequent destination write fails (`runRawCopy_projection`). By contrast, typed aggregate transfers (`*dst = *src` / `MaybeUninit` value copies) reset destination padding to `Uninit` (`typed_transfer_resets_padding`) and transform pointer provenance through an explicit reborrow/tag policy (`raw_and_reborrow_differ`).
2. **Thin-Pointer Provenance Decoding vs. Strict Fragment Coherence and RefinedRust Radium (`MiniRustDecoder`):** MiniRust's `decode_ptr` (`spec/lang/representation.md:112-133`) requires all pointer bytes to be `Init`, but when provenance fragments are missing, mixed across allocations, or at wrong byte positions, it silently strips provenance (`provenance = None`) and returns `Some(ThinPointer { addr, provenance: None })` (`mixed_fragment_counterexample`). By contrast, strict canonical fragment decoding (`Representation.decodePtr`) and RefinedRust's Radium helper `val_to_loc_n` (`zenodo:21636474`, `radium/val.v:128-140`) reject incoherent fragment lists as `None`.
3. **Dead-Allocation Byte Erasure vs. Tombstone Preservation (`DeadData`, `DeadDataExecution`, `DeadDataControls`, `DeadDataWitnesses`):** In `BasicMemory` (`spec/mem/basic.md`), `deallocate` sets `live = false` while retaining the allocation record and historical bytes. Erasing dead-allocation bytes to `Uninit` (`DeadData.normalize`) while retaining allocation IDs, `next` counters, and dead tombstones preserves bidirectional finite-prefix reachability and `NoUB` equivalence (`reference_forward_prefix`, `reference_backward_prefix`, `reference_noUB_iff`) across all syntactic states and allocator candidates. However, deleting dead tombstones turns stale-pointer dereference from `UB` into `unsupported`, and arbitrary `DeadData.Same`-related states do not transport canonical `StateWF` without normalization (`DeadDataControls`).
4. **Information-Order Representation Laws and the `minirust#288` Enum Well-Formedness Gap (`CodecAdmission`, `EnumCoherence`):** MiniRust's generic codec laws (`decode(encode(v)) = Some(v)` and provenance deflation `encode(v) <= bytes`) are stated requirements, not consequences of `Type::check_wf` (`spec/lang/well-formed.md:215-284`). A 1-byte, 2-variant enum whose taggers write `0` and `1` but whose discriminator is `Discriminator::Known(0)` satisfies `Type::check_wf` yet violates value round-trip (`decode(encode(variant 1)) = Some(variant 0)`), proved in both `CodecAdmission.lean` and `EnumCoherence.lean` and confirmed across 7 coherent vs. incoherent shape searches (`probe.py`, `enum_wf_probe.py`).
5. **Target Parameters, Wide-Pointer Union Chunks, Floating-Point Absence, and Standard-Library Primitive Routes:** MiniRust's `Type` grammar omits floating-point types (`tooling/minimize/src/ty.rs:181`), whereas Rust `1.99.0` binary32 operations follow IEEE 754 round-to-nearest-even and saturating float-to-int cast rules across native `aarch64` and `wasm32` targets (`primitive.rs`). In `minimize`, `calc_chunks` (`tooling/minimize/src/chunks.rs:39-47`) marks every `Type::Ptr(_)` as a single pointer word (`DefaultTarget::PTR_SIZE`), causing unions containing a two-word wide pointer (`*const [u8]`) to preserve only `[(0, PTR_SIZE)]` and reset the metadata word to `Uninit`. Finally, Rust `1.99.0` lowers `read_unaligned` and `write_unaligned` through packed `Unaligned<T>` places and `transmute_neo` rather than `copy_nonoverlapping`, whereas `copy_nonoverlapping`, `ptr::copy`, and foreign `__rust_realloc` hit explicit unsupported boundaries in `minimize` (`tooling/minimize/src/bb.rs:117,788`).

## Findings

### 1. Target-Parameterized Byte/Fragment Codecs and Raw vs. Typed Memory Transfers

**Basis:** `source`, `execution`, and `derived`

#### 1.1 Universal Thin-Pointer Fragment Codec vs. MiniRust `decode_ptr` Fallback (`Representation.lean`, `MiniRustDecoder.lean`)

In [`support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/Representation.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/Representation.lean), each physical memory cell is `Cell := uninit | init (byte : Byte) (frag : Option Fragment)` with `Fragment := (allocId, generation, tag, index)`, where `significance : Target -> Fin width -> Nat` maps byte significance to physical offset for both little-endian and big-endian targets:
- `significance_involution`, `decodePtr_encodePtr`, and `both_endian_roundTrips` prove `decodePtr t (encodePtr t p) = some p` for every positive target width, both endian orders, every address byte vector, and optional provenance.
- `decodePtr_eq_some_iff` proves that strict canonical decoding (`Representation.decodePtr`) succeeds if and only if all bytes in `0..t.width` are `init` and carry a uniform fragment matching `p.provenance` at each byte's significance index; negative controls reject `uninit` bytes (`decodePtr_reject_uninit`), wrong indices (`scrambled_fragment_rejected`), missing fragments (`missing_fragment_rejected`), and mixed provenance (`mixed_fragments_rejected`).
- By contrast, transcribing MiniRust's `decode_ptr` (`spec/lang/representation.md:112-133`) in [`support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/MiniRustDecoder.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/MiniRustDecoder.lean) proves (`mixed_fragment_counterexample`, `missingFragment_differ`, `wrongPositionFragment_differ`) that when all 8 bytes are `Init` but fragments are partially missing, mixed, or out-of-order, MiniRust resets its provenance accumulator to `None` (`lines 121-129`) and **still succeeds with `Some(ThinPointer { addr, provenance: None })` at line 132**. RefinedRust's Radium helper `val_to_loc_n` (`radium/val.v:128-140`) and integer decoder `val_to_Z_go` (`radium/val.v:342-347,595-603`) also differ from MiniRust: Radium rejects mixed pointer fragments as `None` and rejects pointer-fragment bytes in integer decoding, whereas MiniRust's integer decoder strips provenance and reads the underlying `u8` digits.

#### 1.2 Snapshot Raw Copies, Out-of-Order Partial Transfers, and Typed Padding Reset (`ByteMemory`, `PartialTransfers`, `Transfers`, `PrefixTransfer`)

Connecting `Representation.Cell` to stateful memory in [`ByteMemory.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/ByteMemory.lean), [`PartialTransfers.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/PartialTransfers.lean), [`Transfers.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/Transfers.lean), [`TransferExamples.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/TransferExamples.lean), and [`PrefixTransfer.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/PrefixTransfer.lean) establishes:
- **Snapshot raw copy (`rawCopy_success`, `runRawCopy_projection`):** Raw reads capture an `AbstractByte` snapshot without decoding values and apply read permission transitions before checking destination write authority (`library/core/src/ptr/mod.rs:576-611`). Raw copy preserves `Uninit`, initialized padding, and partial pointer fragments verbatim, including overlapping ranges; an independent 285-case Python overlap probe (`support/minirust-primitive-lowering-and-layout-frontier-d821c6e/primitive_model.py`) shows that a naive forward-streaming byte loop disagrees with snapshot copy on 34 overlapping ranges (minimal witness: `src = 0, dst = 1, len = 2`).
- **Out-of-order two-piece pointer assembly (`partial_copies_assemble_pointer`):** Copying the upper 2 bytes of a 4-byte pointer leaves an intermediate destination that fails pointer decoding (`partial_copy_alone_rejected`), and subsequently copying the lower 2 bytes reconstructs `some examplePtr`.
- **Typed vs. raw padding and reborrow policy (`typedCopyAggregate_supported`, `raw_and_typed_padding`, `raw_and_reborrow_differ`):** For `#[repr(C)] struct Packet { tag: u8, ptr: *const u8 }` (admissible for `(width, align)` in `{(4, 4), (8, 8), (8, 4)}` by `conditional_packet_layouts` and confirmed as `size = 16, align = 8, ptr_offset = 8` on 64-bit targets by [`support/minirust-d821c6e-representation-transfers-and-codec-coherence/layout-probe.rs`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/layout-probe.rs)), raw copying preserves initialized padding byte `1` (`Init 99 none`) and exact pointer tags, whereas typed aggregate transfer resets destination padding to `Uninit` (`typed_transfer_resets_padding`) and maps pointer provenance through the active reborrow policy (`withTag 19`).

### 2. Dead-Allocation Byte Erasure and Relational Tombstone Correspondence (`DeadData` .. `DeadDataWitnesses`)

**Basis:** `execution` and `derived`

In MiniRust's `BasicMemory` (`spec/mem/basic.md`), `deallocate` marks an allocation dead (`live = false`) while retaining its `Allocation` entry and byte array. Across [`DeadData.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/DeadData.lean), [`DeadDataExecution.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/DeadDataExecution.lean), [`DeadDataControls.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/DeadDataControls.lean), and [`DeadDataWitnesses.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/DeadDataWitnesses.lean):
- **Dead-only normalization (`DeadData.normalize`) and equivalence (`DeadData.Same`):** `DeadData.normalize` overwrites cells with `Uninit` if and only if their allocation ID has metadata with `live = false`, preserving `next`, all metadata tombstones, and all live cells.
- **Universal finite-prefix and `NoUB` correspondence (`reference_forward_prefix`, `reference_backward_prefix`, `reference_noUB_iff`, `encoded_normalized_noUB_iff`):** Without assuming `StateWF`, every primitive operation (`allocate`, `deallocate`, `load`, `store`, `dereferenceable`) and multi-step execution commutes with `DeadData.Same` for every allocator candidate.
- **Why tombstones and normalization are required (`DeadDataControls.lean`):** Deleting a dead allocation's metadata record instead of keeping its `live = false` tombstone changes stale-pointer dereference from `.ub .dead` to `.unsupported`. Moreover, arbitrary `DeadData.Same`-related states do not transport canonical `StateWF` without `DeadData.normalize`, because `StateWF` requires every fragment `allocId` anywhere in storage (even inside dead allocations) to satisfy `allocId < next`.

### 3. Information-Order Representation Laws, Codec Coherence, and the `minirust#288` Well-Formedness Gap

**Basis:** `source`, `execution`, and `derived`

#### 3.1 Information Order (`<=`) and Deflation Laws (`Representation.lean`, `probe.py`)

MiniRust (`spec/lang/representation.md`) orders `AbstractByte` by allowing `Uninit <= b` and `Init(d, None) <= Init(d, Some(p))` (with pointwise extension to lists), and states four consistency laws for well-formed types:
$$\mathrm{decode}(\mathrm{encode}(v)) = \mathrm{Some}(v), \quad \mathrm{decode}(b) = \mathrm{Some}(v) \implies \mathrm{encode}(v) \le b, \quad v_1 \le v_2 \implies \mathrm{encode}(v_1) \le \mathrm{encode}(v_2), \quad b_1 \le b_2 \implies \mathrm{decode}(b_1) \le \mathrm{decode}(b_2).$$
[`support/minirust-representation-copy-provenance-laws-d821c6e/Representation.lean`](support/minirust-representation-copy-provenance-laws-d821c6e/Representation.lean) proves byte-order reflexivity, provenance-stripping deflation, idempotent projection-mask deflation (modeling tuple padding and union chunk forgetting), and provenance-free scalar round-trip. [`support/minirust-representation-copy-provenance-laws-d821c6e/probe.py`](support/minirust-representation-copy-provenance-laws-d821c6e/probe.py) exhaustively verifies round-trip, deflation, and monotonicity across 7 coherent type shapes (`Boolean`, `u8`, 2-byte thin pointer, `u8` + padding, `[u8; 2]`, union with chunk/gap, and coherent 2-variant enum — up to 441 byte vectors and 3,249 ordered pairs per shape, plus 196,608 two-byte pointer round trips).

#### 3.2 The `minirust#288` Enum Coherence Counterexample and Instance Binding (`CodecAdmission.lean`, `EnumCoherence.lean`, `enum_wf_probe.py`)

In `spec/lang/well-formed.md:215-284`, `Type::check_wf` for `Type::Enum` checks variant payload layouts, in-bounds tagger writes, and discriminator tree bounds (`Discriminator::Known(d)` only checks `variants.contains_key(d)`), **without verifying that each variant's `tagger` writes bytes that the `discriminator` decodes back to that variant**.
- **Concrete counterexample ([`support/minirust-representation-copy-provenance-laws-d821c6e/enum-wf-counterexample.json`](support/minirust-representation-copy-provenance-laws-d821c6e/enum-wf-counterexample.json), [`EnumCoherence.lean`](support/minirust-representation-copy-provenance-laws-d821c6e/EnumCoherence.lean), [`CodecAdmission.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/CodecAdmission.lean)):** A 1-byte enum with variants `0` and `1` (1-byte all-padding empty tuples), `u8` taggers writing `0` and `1`, and `Discriminator::Known(0)` satisfies `Type::check_wf` (`StaticAdmission = true`), yet encoding variant `1` produces `[Init 1 none]` and decoding returns `Some(variant 0)`.
- **Six mechanized discriminators in [`CodecAdmission.lean`](support/minirust-d821c6e-representation-transfers-and-codec-coherence/AnnealResearch/CodecAdmission.lean):** (1) admitted coherent `Bool` and `Enum` instances satisfy round-trip and deflation; (2) the `Known(0)` enum passes `StaticAdmission` but fails `EnumCoherent` and round-trip; (3) swapping `normal` (`0->0, 1->1`) and `reversed` (`0->1, 1->0`) coherent enum instances breaks caller dispatch when `advertisedId != selectedId`; (4) missing or out-of-range constant certificates (`arg = 256`) are rejected; (5) an admitted `Bool` decoder steps cleanly to object-language `UB` on `[Init 2 none]`; and (6) decoding `[Init 1 (some 7)]` as `Bool` and re-encoding yields `[Init 1 none]`, satisfying deflation (`<=`) while refuting byte equality (`!=`).

### 4. Target Parameters, Dynamic/DST Layouts, Wide-Pointer Union Chunks, and Primitive Lowering Routes

**Basis:** `source`, `normative`, `documentation`, `execution`, and `derived`

#### 4.1 Target Parameters, Native `aarch64` vs. `wasm32` Controls, and Floating-Point Absence (`target.md`, `operators.md`, `primitive.rs`)

- **Target interface and integer operators (`spec/prelude/target.md`, `spec/lang/step/operators.md:183`):** `Target` fixes `PTR_SIZE`, `PTR_ALIGN`, `INT_MAX_ALIGN`, `ENDIANNESS`, `MAX_ATOMIC_SIZE`, and `valid_size`. MiniRust `Int` is mathematical while `IntType` bounds results: wrapping arithmetic reduces modulo $2^w$, unchecked arithmetic raises UB on overflow, ordinary shifts reduce shift counts modulo bit width $w$, and unchecked shifts require $0 \le \text{shift} < w$. `MAX_ATOMIC_SIZE` is only a width cap, not a per-operation target availability certificate (`library/core/src/sync/atomic.rs:115`).
- **Floating-point absence in MiniRust vs. Rust binary32 rules:** MiniRust `d821c6e` has no floating-point `Type` variant, and `minimize` explicitly rejects `TyKind::Float` and float casts (`tooling/minimize/src/ty.rs:181`). Executing the 32 safe controls in [`support/minirust-primitive-lowering-and-layout-frontier-d821c6e/primitive.rs`](support/minirust-primitive-lowering-and-layout-frontier-d821c6e/primitive.rs) under `rustc 1.99.0` on both native `aarch64-apple-darwin` and `wasm32-unknown-unknown` ([`support/minirust-primitive-lowering-and-layout-frontier-d821c6e/runs/results.json`](support/minirust-primitive-lowering-and-layout-frontier-d821c6e/runs/results.json)) confirms identical Rust numeric outcomes (`2^24 + 1` as `f32` rounds to `0x4b800000`, smallest subnormal doubled is `bits 2`, `-0.0f32.to_bits() == 0x80000000`, `+inf / -inf / NaN as u8 == 255 / 0 / 0`, `-1.9f32 as i32 == -1`, `1u8.wrapping_shl(8) == 1`, `1u8.checked_shl(8) == None`) while exposing target-dependent layout sizes (`usize` and `#[repr(C)] { u8, usize }` are `8` and `16` bytes on `aarch64` vs. `4` and `8` bytes on `wasm32`; a 1-field wide-pointer union is `16` bytes on `aarch64` vs. `8` bytes on `wasm32`).

#### 4.2 Wide-Pointer Validation, Dynamic DST Tails, and the `minimize` Union Chunk Defect (`representation.md:487`, `types.md:200`, `chunks.rs:39`)

- **Wide-pointer and DST validation (`spec/lang/representation.md:487-550`, `spec/lang/types.md:200-255`):** `Pointer<Provenance>` carries `Metadata` (`None`, `ElementCount`, or `VTable`). Safe pointers (`Ref` / `Box`) require `total_size <= isize::MAX`, nonnull aligned address, inhabited pointee, and `mem.dereferenceable(ptr, total_size)`, whereas raw pointers check only metadata validity (`count <= usize::MAX` or valid vtable pointer for the expected trait) without requiring dereferenceability. Neither inspects the pointee's stored value. Both [`support/minirust-target-dst-and-intrinsic-contracts-d821c6e/probe.py`](support/minirust-target-dst-and-intrinsic-contracts-d821c6e/probe.py) and [`support/minirust-primitive-lowering-and-layout-frontier-d821c6e/primitive_model.py`](support/minirust-primitive-lowering-and-layout-frontier-d821c6e/primitive_model.py) verify 32/64-bit slice, ZST (`count = usize::MAX` passes safe size checks when nonnull and aligned even without allocation provenance), wrong-trait vtable, and packed unsized-tail (`head = 1B, tail = 8B align 4` -> ordinary `offset = 4, size = 12, align = 4` vs. `packed(1)` `offset = 1, size = 9, align = 1`) discriminators.
- **Wide-pointer union chunk truncation in `minimize` (`tooling/minimize/src/chunks.rs:39-47`, `spec/lang/representation.md:153,321`):** In `minimize`, `calc_chunks` marks every `Type::Ptr(_)` as occupying only `DefaultTarget::PTR_SIZE` (`1` word), whereas `PtrType::as_wide_pair` encodes slice/trait-object pointers as `2 * PTR_SIZE` bytes (data pointer + metadata word). Consequently, for a union containing a single `*const [u8]` field (16 bytes on 64-bit targets), `calc_chunks` emits `chunks = [(0, 8)]`; during union encoding (`representation.md:321`), bytes `8..16` (the slice length metadata) are reset to `Uninit`, causing a subsequent wide-pointer load to fail with UB (confirmed on the generated MiniRust interpreter in [`support/minirust-primitive-lowering-and-layout-frontier-d821c6e/reused-core/actual-results.json`](support/minirust-primitive-lowering-and-layout-frontier-d821c6e/reused-core/actual-results.json)).

| `alloc::alloc::realloc` / `GlobalAlloc::realloc` | Wrapper calls `__rust_realloc` (`library/alloc/src/alloc.rs:220`); default `GlobalAlloc::realloc` (`library/core/src/alloc/global.rs:273`) allocates, calls `copy_nonoverlapping`, and deallocates | Foreign calls (`__rust_realloc` / `__rust_dealloc`) are rejected by `minimize` (`tooling/minimize/src/bb.rs:788`); `BasicMemory::allocate` has no null-failure OOM branch |

## Boundaries

- **Known not to apply:**
  - Byte equality after `encode(decode(bytes))` does not hold for provenance-bearing scalar bytes (only deflation `encode(v) <= bytes` holds) or for padded aggregates under typed copies (padding resets to `Uninit`).
  - `Type::check_wf` (`spec/lang/well-formed.md:215-284`) does not imply `decode(encode(v)) == Some(v)` for `Type::Enum` without an explicit `EnumCoherent` tagger/discriminator premise (`minirust#288`).
  - `DeadData.Same` equivalence does not transport canonical `StateWF` across unnormalized states containing forged dead-storage fragments (`DeadDataControls.lean`).
  - Classifying Rust `1.99.0` `read_unaligned` / `write_unaligned` as lowering through `copy_nonoverlapping` is false; they lower through packed `Unaligned<T>` places and `CastKind::Transmute`.
- **Not examined:**
  - Multi-byte integer endianness inside `Enum` taggers, nested multi-field `Enum` discriminators, or concurrent weak-memory `Ordering` interactions with byte fragments.
  - Native big-endian Rust compiler execution (the 32/64-bit big-endian checks in `Representation.lean`, `primitive_model.py`, and `probe.py` are mechanized/executable formula evaluations, whereas compiled Rust probes ran on little-endian `aarch64`, `x86_64`, and `wasm32`).
- **Unsupported in inspected upstream `minimize` (`d821c6e`):**
  - Floating-point types and casts (`tooling/minimize/src/ty.rs:181`), `CopyNonOverlapping` MIR statements (`tooling/minimize/src/bb.rs:117`), and foreign allocator functions (`tooling/minimize/src/bb.rs:788`).
- **Unknown / open in normative Rust:**
  - Whether normative Rust operational semantics permits decoding mixed/partial pointer fragments into a provenance-free raw pointer (as MiniRust `decode_ptr` does) or treats incoherent fragments as decode failure (as strict `Representation.decodePtr` and RefinedRust Radium `val_to_loc_n` do).
