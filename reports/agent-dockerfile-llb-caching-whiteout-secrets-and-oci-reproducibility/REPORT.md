# Agentic Dockerfile Synthesis, BuildKit LLB Cache and Secret Lowering, OCI Whiteout Persistence, and Deterministic Image Reproducibility

## Summary

Primary-source synthesis across 12 empirical studies and supply-chain specifications (2017–2026), normative inspection of the OCI Image Format Specification (`opencontainers/image-spec` `v1.1.1` and `4feed4a667`), line-level source analysis of 5 pinned container build and linting implementations (`moby/buildkit@dd75b49550`, `hadolint/hadolint@1d901b9c0b`, `jjhenkel/binnacle-icse2020@00a8fb5220`, `ko-build/ko@caaefc6f61`, `GoogleContainerTools/kaniko@236ba5690e`), and a deterministic Python 3.10+ standard-library verification suite (`scripts/verify_dockerfile_buildkit_oci_repro.py`) establish five invariants governing automated Containerfile synthesis, caching, secret hygiene, runtime signal delivery, and bitwise OCI reproducibility:

1. **Static Dockerfile AST Linters (`Hadolint`, `Binnacle`) Miss Live Package-Index Rot and Exhibit Partial-Index, Pinning-Syntax, and Multi-Stage State Defects (`Probe 1`):** Across open-source GitHub repositories, `26%–34%` of Dockerfiles fail automated builds (`Cito et al., MSR 2017`; `Shipwright, ICSE 2021`) and `~84%` contain static smells (`Wu et al., 2020`), yet `Hadolint` and `Binnacle` flag issues in only **`33.8%`** and **`20.6%`** of `5,400` broken Dockerfiles (`Shipwright`) and explain **`<3%`** of rebuildability or reproducibility variance across `21` rules (`19` `Hadolint` `DL*` + `2` custom `CR*` rules, $R^2 \in [0.05, 0.27]$; `Malka et al., 2026` `Table 7`). In `hadolint@1d901b9c0b`, `DL3000.hs:24` invokes partial `Data.Text.index` without a length check—crashing at `index 0` on `WORKDIR ""` or unbalanced `WORKDIR "\""` (after `Rule.hs:262–267` `Text.dropAround quotes`) and at `index 1` on 1-character alphabetic relative paths (`WORKDIR a`, `WORKDIR "x"`), while short-circuiting cleanly on `WORKDIR .`; `DL3008.hs:24, 31` and `DL3018.hs:31` pass mutable `apt-get install -y curl/bookworm`, `apt install -y curl`, and `apk add --no-cache "curl>7.0"` without warnings, while strict `apt-get` exact pins (`curl=7.88.1-10+deb12u5`) break as soon as live Debian mirrors replace superseded point releases unless paired with an immutable archive snapshot; `DL4006.hs:31–49` triggers false positives on inline `RUN set -o pipefail && ... | ...`; and `Shellcheck.hs:42, 68, 78, 94` skips Exec-form `RUN [...]` (`ArgumentsList`) and omits `DL4006.hs:56`'s `registryName == Nothing` guard while inheriting variables from stage index `0` on colliding stage names. Meanwhile, `Binnacle` Phase 2 (`app.py:19–42`) collapses BuildKit `--mount=` and `<<EOF` heredocs into opaque `"UNKNOWN"` AST nodes.
2. **BuildKit LLB `CacheMap` Selector Hashing Rewards Manifest-First Staging, While Default `CacheSharingOpt_SHARED` + Debian `docker-clean` Defeat Multi-Arch `apt` Cache Mounts (`Probe 2`):** In `moby/buildkit@dd75b49550`, `opsutils.NewContentHashFunc` (`contenthash.go:31–73`) hashes strictly the `Selector` paths feeding an upstream `FileOp`/`ExecOp`. On a 50-commit edit trace (`46` `src/lib.rs` edits [`92.0%`] and `4` `Cargo.lock` edits [`8.0%`] against a warm baseline cache), naive `COPY . .` before `RUN cargo build --release` yields **`0 / 50` (`0.0%`)** cache hits, whereas staging `COPY Cargo.toml Cargo.lock ./` ahead of dependency compilation yields **`46 / 50` (`92.0%`)** hits. Furthermore, `dispatchRunMounts` (`convert_runmount.go:108–120`) defaults `RUN --mount=type=cache` to `llb.CacheMountShared`, handing `4` concurrent multi-architecture builders simultaneous mutable handles (`mount.go:88–92`, `max_concurrent_writers = 4`, `3` `apt` lock collisions), while Debian/Ubuntu's `/etc/apt/apt.conf.d/docker-clean` post-invoke hook deletes all downloaded `.deb` archives (`0 / 12` retained); specifying `sharing=locked` (`mount.go:95–96, 130–139`, `100 ms` `cache.ErrLocked` polling) and removing `docker-clean` serializes writers (`max_concurrent_writers = 1`, `0` collisions) and retains **`12 / 12`** `.deb` archives.
3. **OCI `.wh.` Whiteouts Never Erase Lower-Layer Secrets, and BuildKit `ARG`/`ENV` Leak Plaintext Twice Into `config.json` Whereas `RUN --mount=type=secret` Excludes Secrets Without Masking `commitToHistory` (`Probe 3`):** Across `337,171` combined Docker Hub and private-registry images (`1,647,300` layers), `Dahlmanns et al. (ASIA CCS 2023)` found **`28,621` (`8.5%`)** images leaking `55,265` valid secrets (`52,107` private keys—`30%` from `openssh-server` installs and `8.1%` from `ssh-keygen`—plus `3,158` API secrets). Per normative `opencontainers/image-spec` (`layer.md:246–252, 276–302`), later-layer `rm` commands emit `.wh.<basename>` or `.wh..wh..opq` whiteout entries that hide paths only in the merged union rootfs while leaving lower layer blobs immutable in `manifest.layers[0]` (`2,048 / 2,048 B` of an OpenSSH private key recovered directly from Layer 0 while doubling total uncompressed tar size from `10,240 B` to `20,480 B`, matching `Durieux, ICSE 2024` `Parfum`'s `48.06 MB` [`4.6%`] mean smell bloat). In `moby/buildkit@dd75b49550`, both `ENV` (`convert.go:1370–1374`) and `ARG` (`convert.go:1831–1837` unconditional empty-layer `"ARG KEY=VAL"` commit plus `convert.go:1594, 1910–1930` `"RUN |1 KEY=VAL ..."`) serialize build credentials **twice** in plaintext inside `config.json`. By contrast, `RUN --mount=type=secret,id=api_token,env=API_TOKEN ./fetch.sh` records `"RUN /bin/sh -c ./fetch.sh"` with **`0` plaintext `config.json` occurrences** because `dispatchSecret` (`convert_secrets.go:17–90`) excludes secrets from `d.buildArgs`, `d.state`, and `d.image.Config.Env`—whereas `withSecretEnvMask` (`convert.go:1561–1562`, `convert_secrets.go:92–112`) masks only the `llb.WithCustomName` solver progress label and does **not** scrub a shadowed same-named `ARG` from `commitToHistory` at `L1594` (`2` leaks of the `ARG` fallback value).
4. **Exec-Form `ENTRYPOINT` Avoids PID-1 `/bin/sh` `SIGTERM` Blackholes, and Per-Command Atomic Container Rollback Prevents Interactive State Divergence (`Probe 4`):** Multi-language environment synthesis remains brittle (`Multi-Docker-Eval, ACL 2026 Findings`: `SWE-Builder` peaks at `37.72%` F2P on `DeepSeek-v3.1` across `40` repos in `9` languages, while `RepoLaunch` averages `8.85% ± 3.11%` F2P and `1.42 ± 0.09 GB` image size [`1.19–1.55 GB` across 10 models]). At container runtime, shell-form `ENTRYPOINT python3 app.py` lowers via `withShell` (`convert.go:1709–1725, 2030–2038`) to `["/bin/sh", "-c", "python3 app.py"]`, placing non-forwarding `sh` at PID 1 (`30.0 s` Kubernetes `SIGTERM` timeout ending in `SIGKILL` exit `137`), whereas Exec-form `ENTRYPOINT ["python3", "app.py"]` and `ko`'s `[]string{appPath}` (`gobuild.go:1313`) exec the target binary at PID 1 (`0.02 s` graceful exit `0`). During synthesis, compound commands (`apt-get install -y libgomp1 && pip install nonexistent-wheel`) that fail midway pollute live interactive containers so subsequent tests pass interactively while clean `docker build` fails; `Repo2Run` (`NeurIPS 2025`, `§3` & `§4.5` `Table 3`) prevents this divergence via dual-environment synthesis (`-44.3` percentage-point EBSR drop when ablated) and atomic container rollback (`-3.1%` DGSR / `-2.4%` EBSR drop when ablated).
5. **Bitwise OCI Reproducibility Fails Under BuildKit's Upper-Bound-Only `rewrite-timestamp` Clamp Unless Paired With Canonical `uid`/`gid`, Sorted Tar Walks, Clamped `gzip` Headers, and Base-`DiffID` Preservation (`Probe 5`):** Rebuilding `5,298` historical 2023 GitHub Actions Docker builds (`Malka et al., 2026`) succeeded on `3,836` (`72%`), but across `1,537` downloadable historical images (`1,116` [`72.6%`] rebuildable), **`0 / 1,116` (`0.0%`)** matched historical OCI digests and only **`4 / 1,537` (`0.3%`)** were file-content-identical (`>34.4%` median file-hash drift). Source and PAX tar/gzip verification show four distinct failure modes in `BuildKit` `rewriteTimestampInTarHeader` (`util/converter/converter.go:76–88`): because `if hdr.ModTime.After(epoch) { hdr.ModTime = epoch }` is strictly an **upper-bound clamp**, future `SOURCE_DATE_EPOCH` (`1800000000 > t1, t2`) and mid-interval `SOURCE_DATE_EPOCH` (`t1 < 1700000500 < t2`) leave lower file mtimes unaligned; even at `SOURCE_DATE_EPOCH = 0`, `Uid`/`Gid` (`1000` vs. `1001`), directory walk order, and unclamped RFC 1952 `gzip` header `MTIME` (`bytes[4:8]`) break digest determinism (mitigated across Go compiler upgrades by BuildKit's frozen `newGo126GzipWriterLevel` at `util/compression/gzip.go:57–67`). Conversely, `ko` (`gobuild.go:629–703, 727–904, 1201–1257`) achieves bitwise reproducibility by construction via lexicographically sorted paths, fixed `Mode: 0555`, `Uid/Gid: 0`, deterministic `ModTime`, and `gzip(mtime=0)`, while archived `kaniko@236ba5690e` exhibits cross-device hardlink corruption (`tar_util.go:40, 205–212` keys solely on `stat.Ino` without `stat.Dev` and leaks raw host root `"/kaniko-root/etc/a.conf"` into `hdr.Linkname`) and rewrites upstream base-image `DiffID`s under `--reproducible` via `mutate.Canonical(sourceImage)` (`build.go:783–787`, unlike `BuildKit` `writer.go:477–482`).

### 2. Static Dockerfile AST Linters (`Hadolint` & `Binnacle`) vs. Live Package-Index Drift (`Probe 1`)

#### 2.1 Uncaught Partial `Data.Text.index` Crash in `Hadolint` `DL3000`

`Basis: source + execution`

In `hadolint/hadolint@1d901b9c0b`, `src/Hadolint/Rule.hs:262–267` defines `dropQuotes = Text.dropAround quotes` (stripping arbitrary leading and trailing `"` or `'` characters, equivalent to `text.strip("\"'")`), and `src/Hadolint/Rule/DL3000.hs:14–25` checks `WORKDIR` arguments after `dropQuotes`:

```haskell
isWindowsAbsolute path
  | Char.isLetter (Text.index path 0) && (':' == Text.index path 1) = True
  | otherwise = False
```

Because `Data.Text.index` is a partial function that throws an uncaught exception on out-of-bounds indices and `DL3000.hs` performs no length guard prior to indexing:
- Standard relative paths (`WORKDIR relative/dir`, `WORKDIR ./a`) and 1-character non-alphabetic `WORKDIR .` (`dl3000_dot_short_circuit = "FAIL_DL3000"`, because `Char.isLetter '.'` evaluates to `False` and short-circuits `&&` before `Text.index path 1`) emit `DL3000` cleanly.
- Empty quoted `WORKDIR ""` and unbalanced single-character `WORKDIR "\""` strip to `""` via `Text.dropAround quotes` and crash immediately at **`Data.Text.index: index 0 out of bounds`** (`dl3000_unbalanced_quote_crash_index0 = true`).
- Every 1-character alphabetic relative path (`WORKDIR a`, `WORKDIR "x"`) satisfies `Char.isLetter (Text.index path 0)` and crashes at **`Data.Text.index: index 1 out of bounds`** (`dl3000_crash_inputs = ["WORKDIR a", "WORKDIR \"x\"", "WORKDIR \"\""]`).

#### 2.2 Syntactic Version-Pinning Bypasses (`DL3008`, `DL3018`) and Temporal Archive-Index Rot

`Basis: source + execution + derived`

- **Syntactic False Negatives (`source + execution`):** `src/Hadolint/Rule/DL3008.hs:24, 31` checks `"=" `Text.isInfixOf` package || ("/" `Text.isInfixOf` package || ".deb" `Text.isSuffixOf` package)` exclusively over `apt-get install` commands. ### 5. PID-1 `SIGTERM` Shell Blackholes and Dual-Environment Atomic Rollback (`Probe 4`)

`Basis: source + execution + derived`

1. **Shell-Form vs. Exec-Form `ENTRYPOINT` (`moby/buildkit@dd75b49550:convert.go:1709–1725, 2030–2038`; `ko@caaefc6f61:gobuild.go:1313`; `hadolint@1d901b9c0b:DL3025.hs:7–17`):**

### 6. `SOURCE_DATE_EPOCH` Upper-Clamp Traps, `gzip` Header Drift, `ko`, and `kaniko` Layer Bugs (`Probe 5`)

#### 6.1 Four Digest-Determinism Traps Under BuildKit `rewrite-timestamp`

`Basis: source + execution`

In `moby/buildkit@dd75b49550`, `exporter/util/epoch/parse.go:14–86` parses `SOURCE_DATE_EPOCH` and `exporter/containerimage/writer.go:454–496, 842–849` applies `util/converter/converter.go:76–88` (`rewriteTimestampInTarHeader`) when `rewrite-timestamp=true`:

```go
if hdr.ModTime.After(epoch) {
    hdr.ModTime = epoch
}
```

Building real PAX tar and `gzip` layers at `t1 = 1700000100` and `t2 = 1700000900` over identical file payloads in `Probe 5` demonstrates four distinct non-reproducibility modes:
1. **Unnormalized builds (`unnormalized_diffid_equal = false`):** Divergent `mtime`, `Uid`/`Gid` (`1000` vs. `1001`), and filesystem walk order produce distinct uncompressed `DiffID`s.
2. **Future-epoch upper-clamp no-op (`buildkit_future_epoch_clamp_diffid_equal = false`):** Because `rewriteTimestampInTarHeader` clamps **only** timestamps strictly greater than `epoch`, setting `SOURCE_DATE_EPOCH = 1800000000` (`> t1, t2`) leaves `t1` and `t2` completely unmodified.
3. **Mid-interval asymmetric clamp (`buildkit_mid_epoch_clamp_diffid_equal = false`):** Setting `SOURCE_DATE_EPOCH = 1700000500` (`t1 < epoch < t2`) clamps `t2 -> 1700000500` while leaving `t1 = 1700000100`, still diverging.
4. **Residual `Uid`/`Gid`, walk-order, and RFC 1952 `gzip` `MTIME` drift (`buildkit_epoch0_with_uid_order_drift_equal = false`, `gzip_unclamped_mtime_digest_equal = false`):** Even at `SOURCE_DATE_EPOCH = 0` (`1970-01-01T00:00:00Z`), `rewriteTimestampInTarHeader` does not normalize `Uid`/`Gid` or tar entry ordering; and even when uncompressed `DiffID`s match (`buildkit_epoch0_clean_diffid_equal = true`), unclamped `gzip` streams embed wall-clock `MTIME` in RFC 1952 header `bytes[4:8]`, changing the compressed `manifest.layers[].digest` (further compounded across Go standard-library `compress/flate` changes unless pinned via BuildKit's frozen `newGo126GzipWriterLevel` at `util/compression/gzip.go:57–67` after Go 1.27 `CL 707355`, or deterministic `zstd` at `util/compression/zstd.go:13–20`).
