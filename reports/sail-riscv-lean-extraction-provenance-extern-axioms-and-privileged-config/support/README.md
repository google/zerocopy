| `axiom_cone.py` | Syntactic, over-approximate axiom-cone tool for Sail-generated Lean trees. It builds a name-level reference graph over top-level declarations, strips comments and string literals, and counts dotted tokens only when they are qualified by a model namespace. It then reports which `axiom` declarations are reachable from given roots. This mimics Lean's `CollectAxioms` at source-token level, so it does not follow elaboration-introduced constants. | `git clone https://github.com/opencompl/sail-riscv-lean && cd sail-riscv-lean && git checkout 51c635c460125ac87955d061fcd902ce03b8011f && python3 axiom_cone.py LeanRV64D try_step execute ext_decode execute_RTYPE execute_ITYPE execute_MUL execute_DIV execute_LOAD execute_STORE execute_LOADRES execute_STORECON execute_SRET execute_MRET execute_SFENCE_VMA execute_FENCEI execute_WFI execute_ECALL execute_CSRReg trap_handler translateAddr vmem_read vmem_write dispatchInterrupt read_CSR write_CSR` | `axiom_cone_opencompl.txt` |
| | same tool on the scoped riscv-zkvm extraction | `git clone https://github.com/Verified-zkEVM/riscv-zkvm && cd riscv-zkvm && git checkout 6810fc14d9c40373101321cefaec59df8d82e3e7 && python3 axiom_cone.py RiscvZkvm/Sail <same roots>` | `axiom_cone_riscv_zkvm.txt` |
| `ExternEncodings.lean` | Compares three encodings of an uninterpreted extern (`axiom`, `opaque`, explicit structure parameter) under `#print axioms`, using `#guard_msgs`. Imports only `Init`. | `<lean-4.34.1>/bin/lean ExternEncodings.lean` | exit 0 and no output; all three `#guard_msgs` pass. Removing `noncomputable` from `sc_ax` yields `error(lean.dependsOnNoncomputable): 'match_reservation_ax' not supported by code generator`. |
| `WhileLoopCone.lean` / `WhileLoopCone.out` | Shows what a Lean `while` loop (the lowering Sail uses for an unmeasured loop) contributes to the kernel constant cone. | `<lean-4.34.1>/bin/lean WhileLoopCone.lean` | stdout identical to `WhileLoopCone.out` |
