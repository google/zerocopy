## Claim-mapped source findings

Four of R566's five pinned Salsa files retain the same Git blob and content hash at selected `master`: `README.md`, `book/src/reference/algorithm.md`, `book/src/tuning.md`, and `book/src/plumbing/database_and_runtime.md`. The pinned [`book/src/cycles.md`](https://github.com/salsa-rs/salsa/blob/a7f8c558555f179ca02f6bdf7397d1317f91aa43/book/src/cycles.md) changed at [current `master`](https://github.com/salsa-rs/salsa/blob/30b614d826d697c47bc0f21591fab218f2004032/book/src/cycles.md). It now states that `cycle_initial` and an initial `cycle_result` fallback must not directly create tracked structs; they can return a tracked struct created by another tracked query. This is a new documented constraint within R566's cycle/fixed-point source area. It does not revise every cycle claim in the original report.

Adjacent Salsa implementation files also changed: [`src/function/fetch.rs`](https://github.com/salsa-rs/salsa/blob/30b614d826d697c47bc0f21591fab218f2004032/src/function/fetch.rs) records initial cycle-query reads and asserts against directly owned tracked structs; [`src/function/execute.rs`](https://github.com/salsa-rs/salsa/blob/30b614d826d697c47bc0f21591fab218f2004032/src/function/execute.rs) records a previous-result read during recovery; [`src/active_query.rs`](https://github.com/salsa-rs/salsa/blob/30b614d826d697c47bc0f21591fab218f2004032/src/active_query.rs) adds that dependency record. A new [`tests/cycle_initial_tracked_struct.rs`](https://github.com/salsa-rs/salsa/blob/30b614d826d697c47bc0f21591fab218f2004032/tests/cycle_initial_tracked_struct.rs) contains source tests for the restriction and helper-query case. The tests were not executed. Other Salsa implementation paths changed in this range and were not audited as a complete dependency closure. The findings establish a specific source/documentation delta, not runtime correctness or incompatibility for an Anneal use case.
