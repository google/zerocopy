Key upstream `ref_prop.rs` (`L1-467`) vs. `lean-miri` semantic coupling invariants uncovered and mechanized:

1. **Preliminary `move -> copy` on pointer locals (`ref_prop.rs:93-118`) vs. `deinitMovedPlace = true`:** Upstream `ReferencePropagation` begins by rewriting `Operand::Move(place)` to `Operand::Copy(place)` for pointer-typed locals so reborrow propagation can copy the underlying pointer multiple times. Under Anneal's and `lean-miri`'s `deinitMovedPlace = true` semantics, an unconditional `move -> copy` rewrite is unsound if a subsequent path reads the moved-from pointer local before re-initialization (converting `DeadLocal` / uninit UB into defined execution). `checkMoveToCopyPointers` (`Part II`) enforces backward `mayReadBeforeKill` dataflow verification over the CFG (`CE9`), making `moveToCopyPointers_sound_bidirectional_iff` bidirectionally exact (`↔`).
2. **5-state Tree Borrows permission lattice & Two-Phase `.reservedFrz` tolerance (`Permissions.lean:62-112`, `CE12`):** Unlike Stacked Borrows (where `&mut x` immediately pops/invalidates shared readers), Tree Borrows initializes `&mut x` on a `Freeze` type in `.reservedFrz`, tolerating foreign reads (`y = copy x`) *prior* to the first child write `*r = ...` (which activates `.reservedFrz -> .unique`), while any foreign write (`x = 99` or `*raw = 99`) transitions `.reservedFrz` / `.unique` / `.frozen` to `.disabled` and any foreign read after activation demotes `.unique -> .frozen`. `Slice3a_TbIso` and `Slice3b_RefPropStep` prove that `BorrowLinkMode` abstract dataflow (`checkMirRefPropStep`) accepts Two-Phase `.reservedFrz` pre-activation foreign reads (`progCe12TwoPhaseReservedForeignReadOk` -> `15_u32`) while rejecting all three foreign-write / post-activation foreign-read aliasing hazards (`CE12`).
3. **`skipValidityForSimpleDeref = true` destination-deref evaluation order (`Rvalue.lean:53`, `PointerPlaceMachine.lean:128-133`, `CE13`):** On `(*p) = rvalue`, `lean-miri` evaluates `p`'s pointer slot *before* `evalRvalue` (so an uninitialized pointer local `p` faults `.fault .undefined` even when `rvalue` would fault `.fault .unsupported`), yet defers pointee liveness, epoch, and Tree Borrows `childWrite` validation until *after* `evalRvalue` (so an initialized dangling pointer `p = &raw mut x; StorageDead(x); *p = UnOp.neg(1_u32)` faults `.fault .unsupported` on the RHS before write-time UAF!). Replacing `*r` with `x` (`⟨x, []⟩ = rvalue`) is bidirectionally fault-kind-preserving ONLY when `r` is statically guaranteed initialized and `x` is statically guaranteed live at `r`'s epoch with active write permission at every rewritten `*r` site—exactly the invariant enforced by `checkMirRefPropStep`.
4. **Indirect self-overlap UB (`Place.lean:352-381`, `CE5`) & `*const T` vs. `&T` mutability split (`CE11`):** In MIR, direct scalar `x = copy x` on a non-ZST local is rejected or lowered carefully, and indirect `*p = copy x` / `x = copy *p` / `*p = copy *q` when `p, q` alias `x` faults `.fault .undefined` via `copyRangesOverlap` on non-ZST types (`size > 0`), whereas 0-byte ZST `()` self-copy succeeds (`size == 0`). Meanwhile, writing through `&T` (`MirTy.ref .shared`) faults `.fault .undefined` (`childWrite .frozen = none`), whereas writing through `*const T` (`MirTy.rawPtr .shared`) is ill-typed MIR and faults `.fault .unsupported` (`CE11`).

## Boundaries

1. **Thin local scalar/ZST pointees & value-only ABI boundary (`known not to apply`).** `M_refPtr` models thin local pointers (`&T`, `&mut T`, `*const T`, `*mut T`) to supported scalar/ZST locals (`1..locals.length - 1`) with single-level `ProjectionElem.deref` (`[ProjectionElem.deref]`, plus two-hop reborrow `Rvalue.ref _ ⟨q, [.deref]⟩` / `Rvalue.addressOf _ ⟨q, [.deref]⟩`). Wide pointers (`&[T]`, `&str`, `&dyn Trait`), field-projected sub-object borrows (`&x.f`), multi-deref chains `**pp` in a single `Place`, `UnsafeCell` (`!Freeze` `.reservedIm` interior mutability), function calls (`isProtected = true` protector semantics), and references/pointers in ABI boundary slots (`_0` and `1..=argumentCount` while `CallerMemory` is empty) step fail-closed to `.fault .unsupported`.
2. **Conservative ZST local-liveness check vs. `ValidityMachine.lean:147`.** In `M_refPtr`, dereferencing or creating a safe reference to a 0-byte ZST local (`()` or 1-variant ZST `enum`) still checks that `targetLocal` is live at `targetEpoch` (`readTargetSlotRef` / `writeTargetSlotRef`), while skipping byte-range Tree Borrows transitions on 0-byte accesses (matching `AllocationAccess.lean:67` and `DedupRangeMap.lean:82`). As empirically confirmed in `support/zerocopy_refprop_and_remove_zsts_census.json` (`part_a_remove_zsts_miri_ub_erasure`), upstream Miri's 0-byte fast path accepts `*null::<()>()` without UAF; `M_refPtr`'s stricter liveness requirement conservatively rejects dangling-ZST-local dereferences as `.fault .undefined` so that rewriting `*r -> x` (which checks `StorageLive(x)` in `Trusted.MirSemantics`) preserves exact bidirectional fault equivalence (`↔`).
3. **Pointer arithmetic, comparisons, & provenance casts fail closed.** `BinOp.offset`, `UnOp.ptrMetadata`, pointer equality/ordering (`BinOp.eq`..`BinOp.ge` on `.ref`/`.rawPtr`), and pointer-to-integer casts fail closed to `.fault .unsupported` via `isPrimitiveReadableTy`, matching `Trusted.MirSemantics` (`mirProfileVersion = 1`).
4. **SSA single-definition scope of `checkMirRefPropStep` vs. full upstream `ref_prop.rs`.** Each `RefPropStep.propagateSsaRef ⟨bodyIdx, r, x⟩` certifies propagating a non-parameter pointer local `r` whose non-storage assignments all target the same root local `x` (directly or via a dominating pointer `q` already linked to `x`) and eliminates `100%` of non-storage mentions of `r` (`!bodyMentionsLocalExceptStorage r`).
