### Edge cases checked

- Zero-sized `Self`: the slice is empty but remains non-null and aligned; `read_exact` succeeds without access.
- `Self` with padding: padding is initialized before the byte-slice reference is created; later loss of padding on the value move is harmless.
- Interior mutability: the conversion uses exclusive aliasing, so no `Immutable` bound is needed.
- `Drop`: error/unwind paths hold only `MaybeUninit<Self>`; success constructs a valid `Self`. Any sound `FromBytes` impl for a drop type must make every byte pattern safe as a value, including eventual destruction.
- Incorrect manual `FromBytes`/`FromZeros`/`KnownLayout` impls remain the unsafe implementor’s contract violation, not a defect in this method.
