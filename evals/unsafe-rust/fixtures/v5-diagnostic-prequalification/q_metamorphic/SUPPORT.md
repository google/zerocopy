# Review scope

This snapshot is scoped to Rust 1.83.0, edition 2021, on all targets and in
all profiles supported by that toolchain. The selected dependency is exactly
`peer-text` 3.0.0.

The dependency implementation, build inputs, generated sources, and binary
artifacts are unavailable. `DEPENDENCY-API.md` is the complete supplied
dependency evidence. `caller_examples.rs` is a downstream-crate fragment,
not part of the library crate. There are no build scripts or conditional
compilation attributes.
