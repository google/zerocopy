# Corpus binding starter

Replace the instance placeholders before using this binding. This document is
selected only when the caller supplies its absolute path, operation and stopping
boundary. The corpus root is the parent of that selected file. All paths below
are relative to that root; installation and cwd do not select it.

| Selection | Resource |

Read complete selected policy, format, machine vocabulary and research resources
before dependent work. Do not repeat vocabulary here. The shared contract owns
report meanings; project policy owns visibility, actions, additional requirements
and publication. Missing resources, unsupported interpretation or conflicts block
dependent operations. Keep a separate binding for each scope.

The caller selects planning, maintenance, or an authorized publication operation.
Planning stops at questions and investigation tracks. Maintenance produces final
report packages and regenerates the catalog when metadata or package names change.
This binding grants no publication authority. Follow current project policy,
candidate validation, concurrency and readback rules for an authorized publication.

Basic research and maintenance need no navigator, index, global skill installation
or authoring checkout. Optional navigation requires its own explicit executable,
source/index and cache selection. Preserve independently selected historical
reader payloads and old images/handles until a qualified replacement exists.
